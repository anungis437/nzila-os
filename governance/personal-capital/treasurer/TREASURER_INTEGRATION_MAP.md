# TREASURER integration map

Repository truth does not contain a pre-existing executable Fleet of these peers. TREASURER extends the governed-agent and doctrine-citation patterns already in the repo and draws a hard boundary against corporate capital. It does not inherit peer authority.

CAPITAL = enterprise/venture capitalization and corporate capital strategy.

TREASURER = Principal's personal investment-capital intelligence and stewardship.

NORTHSTAR = Principal's long-horizon ambitions and dream portfolio.

COMMAND = execution authority within governed missions.

| Peer | Repository truth | Relationship |
| --- | --- | --- |
| CAPITAL | `scripts/lib/capital-allocation.ts`, `governance/corporate/finance/` | Corporate product-capital decisions such as FUND NOW. Refused as personal holdings. |
| COMMAND | Application command buses, including `apps/flow` | TREASURER does not dispatch commands. |
| COUNCIL | No personal-capital council runtime | May be informed by a report. Cannot grant authority. |
| ORACLE | Runtime schema oracle under `tooling/db/canonical-schema/` is not a personal-capital oracle | Its output is not a holding or a price. |
| SCOUT | No scout runtime | Outside text stays IDEA or RESEARCH until evidenced. |
| RED_TEAM | `packages/treasurer/src/red-team.ts` | Attacks TREASURER. Cannot authorize. |
| VERIFIER | `packages/treasurer/src/verifier.ts` | Re-executes gates. Cannot authorize a transaction. |
| CHRONICLE | No chronicle runtime | Thesis and decision history inside TREASURER is append-only. |
| COUNSEL | Corporate legal agent in ExecutiveOS is not personal tax counsel | Tax context exists only when evidence is supplied. |
| NORTHSTAR | `packages/treasurer/src/northstar.ts` | Receives capacity reports. Cannot fabricate capacity. |

The corporate ExecutiveOS treasury agent (`packages/executive-os/src/agents/treasury.ts`, key `treasury`) protects corporate cash reality. It is not TREASURER and cannot silently become a proxy.

TREASURER does not inherit any peer listed above.
