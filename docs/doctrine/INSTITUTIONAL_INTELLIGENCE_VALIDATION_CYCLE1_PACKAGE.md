## 3) Baseline Hypotheses (Pre-Registered)

1. Problem Recognition
Expected strongest in labour, municipal, and association contexts and moderate in healthcare where operational maturity language is already established.

2. Executive Comprehension
Expected curiosity is high, with initial AI confusion if memory and continuity are not emphasized.

3. Competitive Distinction
Expected incumbents to be seen as strong in tools but weak in integrated memory-continuity-governance-trust architecture.

4. Product Traceability
Expected Union Eyes and TrustCore to map strongly; Memora to require explicit dignity-centered memory and care continuity framing.

5. Category Independence
Expected majority yes when category is framed as organizational capability rather than platform label.

6. Market Timing
Expected strong more important signal driven by AI adoption, leadership turnover, governance complexity, and trust pressure.

7. Causal Model
Expected Model B to win because trust is earned through observed governance quality.

## 5) Post-Interview Coding Discipline (Cycle 1 Lock)

1. Score all tests immediately after each interview.
2. Capture one verbatim pain statement from every interview.
3. Capture one verbatim confusion or objection statement if present.
4. Capture one verbatim curiosity signal if present.
5. Assign restatement quality High, Medium, or Low before ending notes.
6. Mark AI reduction as Yes or No using the first reaction, not later clarification.
7. Do not rewrite prompts during Cycle 1.
8. Log any moderator deviations in notes.

---

## 6) Weekly Cadence and Control Points

### Weekly cadence
1. Run interview blocks in batches of 3-5.
2. Update tracker and live metrics after each batch.
3. Review sector balance weekly.
4. Escalate risk if any gate metric trends below threshold.

### Control points
1. Control Point A (after 5 interviews): check AI reduction and comprehension drift.
2. Control Point B (after 10 interviews): check Test 0 and timing direction.
3. Control Point C (after 12 interviews): evaluate whether to extend to 16-20.

## 7) Go/No-Go Meeting Agenda (60 minutes)

### 0. Opening and objective (5 minutes)
- Confirm decision scope: Go, No-Go, or Conditional Go.

### 1. Sample integrity review (10 minutes)
- Sector distribution
- Role quality
- Any sampling bias

### 2. Quantitative gate review (15 minutes)
- Test 0 through Test 6 against thresholds
- Highlight pass/fail and borderline metrics

### 3. Qualitative evidence review (15 minutes)
- Top confirmation signals
- Top objections
- Top misinterpretation patterns

### 4. Canonical decisions (10 minutes)
- Category name status
- Definition status
- Model freeze decision
- Vocabulary changes needed

### 5. Decision and next artifact authorization (5 minutes)
- Go: authorize Introducing Institutional Intelligence
- Conditional Go: define revision and re-test scope
- No-Go: define reset plan and interview extension
