# IEBOK Constitutional Metamodel (Remediation Extension)

## Meta-Types (Primary)
E Enduring Entity · V Event · P Process · Q Quality · R Relationship · S State · A Artifact · C Capability · K Constraint

## Multi-Typing Rules
1. Every concept must declare **one primary meta-type**.
2. Secondary characterization is allowed only with an explicit non-conflation note.
3. State is never a substitute for entity, quality, capability, or relationship.
4. Artifact descriptions do not redefine ontology.
5. Process participation does not change primary type.
