## 0) Baseline Hypotheses Before Cycle 1

1. Problem Recognition
Expected: strongest in labour, municipal, and association contexts; moderate in healthcare due to existing operational maturity language.

2. Executive Comprehension
Expected: Institutional Intelligence will trigger curiosity but may initially be mistaken for AI unless memory and continuity are emphasized.

3. Competitive Distinction
Expected: incumbents will be seen as strong in tools and weak in integrated memory-continuity-governance-trust architecture.

4. Product Traceability
Expected: Union Eyes and TrustCore will map strongly; Memora will require careful framing around dignity-centered memory and care continuity.

5. Category Independence
Expected: majority yes if category is framed as organizational capability, not platform.

6. Market Timing
Expected: strong more important response due to AI adoption, leadership turnover, governance complexity, and trust pressure.

7. Causal Model
Expected: Model B wins because observable governance is how institutional trust is earned.

## 5) Coding Discipline (Do Not Skip)

1. Capture verbatim phrase for each AI reduction response.
2. Capture one verbatim phrase for each strong curiosity response.
3. Capture one verbatim pain statement per interviewee.
4. Code restatement quality immediately after call.
5. Do not change category definition wording mid-cycle.

## 6) Interview Ops Checklist

### Before cycle starts
1. Freeze prompts and model variants.
2. Confirm sample quotas by sector.
3. Assign interviewer and note-taker roles.
4. Pre-create interview IDs.

### During cycle
1. Complete score row immediately after each interview.
2. Run weekly metric rollup.
3. Flag drift in prompt wording.

### End of cycle
1. Complete dashboard.
2. Draft evidence memo.
3. Hold go/no-go review.
4. Approve next artifact only if gate passes.
