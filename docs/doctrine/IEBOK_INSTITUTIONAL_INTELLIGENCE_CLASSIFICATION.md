# IEBOK Institutional Intelligence Classification Record

## Determination
**Provisional constitutional classification:** Quality (primary) with second-order construct characterization.

## Rationale
Institutional Intelligence is best modeled as a systems-level quality borne by an institutional system and constituted through integrated capabilities (governance, continuity, knowledge, adaptive response). Current evidence supports quality framing but does not conclusively eliminate neighboring models.

## Comparative Assessment
| Candidate model | Assessment |
|---|---|
| Quality | Best current primary fit |
| Capability | Component-level, not full construct |
| Composite capability | Useful partial lens; under-specifies evaluative/system property aspects |
| State | Snapshot only; misses persistent dispositional aspects |
| Systems property | Compatible as secondary characterization |
| Maturity condition | Assessment framing, not ontology |
| Emergent outcome | Partial dimension, not total construct |
| Relational quality | Partial; misses internal integration dimension |
| Second-order construct | Strong secondary characterization |

## Constitutional Clarifications
- **What kind of thing:** systems-level institutional quality.
- **What possesses it:** institutional system (enduring entity).
- **Continuity/degrees:** continuous by degree, not binary.
- **Observable/latent:** primarily latent, inferred via indicators under Ch. I rules.
- **Difference from resilience:** resilience concerns shock absorption/preservation; II concerns integrated institutional cognition-governance-adaptation quality.
- **Difference from knowledge:** knowledge is one component domain; II is integrated cross-domain quality.
- **Difference from governance quality:** governance quality is a component, not total construct.
- **Relation to performance:** contributory, not identical to performance outcomes.
- **Objective vs descriptor:** both descriptive property and legitimate engineering objective.

## Open Research Question
RQ-II-01: Do governance, continuity, knowledge, and adaptive-response dimensions exhibit stable non-redundant construct structure across institutional types sufficient for final non-provisional closure?

## Interim Rule
Use provisional classification in constitutional text until RQ-II-01 evidence threshold is met.
