## 1) Gate Objective

Validate whether **Institutional Intelligence** can function as a durable external category rather than an internal framing.

The gate must prove five outcomes:

1. The market recognizes the pain.
2. Executives understand the category quickly.
3. The category is defensible against incumbents.
4. The category naturally maps to current and future products.
5. The market timing is favorable for category adoption.

---

## 2) Working Assumptions (Freeze Until Evidence Contradicts)

### Category Name
Institutional Intelligence

### Core Definition
Institutional Intelligence is the governed capacity of institutions to remember, decide, adapt, and remain legitimate over time.

### Working Model (Primary Candidate)
Memory -> Continuity -> Governance -> Trust -> Institutional Intelligence -> Resilience

### Core Problem Statement
Organizations are becoming more digitally capable while becoming more institutionally fragile.

---

## 3) Interview Design

### Sample Size
12-20 interviewees across:

1. Labour leaders (union presidents, executive directors)
2. Healthcare executives (hospital COO/CIO/quality leaders)
3. Municipal executives (CAO, city manager, governance leads)
4. Association/non-profit CEOs
5. Regulator or board-level governance actors

### Interview Length
30-40 minutes

### Moderation Rules

1. Test the category without Nzila branding first.
2. Ask open questions before introducing definitions.
3. Capture verbatim responses.
4. Score immediately after each interview.
5. Do not persuade respondents during the interview.

---

## 4) Test Battery

## Test 0 — Problem Recognition (Required)

### Prompt
How much of your organization's risk comes from loss of knowledge, leadership transitions, inconsistent decisions, fragmented accountability, or difficulty preserving institutional memory?

### Scale
1. No meaningful issue
2. Minor issue
3. Moderate issue
4. Significant issue
5. Strategic risk

### Pass Threshold

1. Mean score > 3.5
2. At least 70% identify one continuity or memory-related risk unprompted

### Fail Meaning
The category is solving a pain not yet recognized by the market.

---

## Test 1 — Executive Comprehension (30 seconds)

### Category Prompt (No company mention)
Institutional Intelligence is the governed capacity of institutions to preserve memory, maintain continuity, govern accountably, and remain legitimate through change.

### Questions

1. What do you think this means?
2. Is this useful language in your context?
3. Can you restate it in your own words in 20 seconds?

### Pass Threshold

1. 70%+ respond with curiosity instead of reducing it to generic AI
2. 60%+ restate using at least 3 core terms

---

## Test 2 — Competitive Distinction

### Prompt
If a major incumbent announced this category tomorrow, would that feel credible to you?

### Competitors to Test

1. Microsoft
2. Salesforce
3. ServiceNow
4. Gartner
5. Deloitte

### Score Each Competitor (0-5)

1. Memory integrity depth
2. Continuity architecture depth
3. Accountable governance depth
4. Trust operations depth

### Pass Threshold

1. No incumbent credibly owns all four dimensions without major repositioning
2. Nzila-style integration is viewed as structurally distinct

---

## Test 3 — Product Traceability

### Prompt
How would a product need to behave to strengthen Institutional Intelligence in your organization?

### Internal Mapping Requirement
For each current or proposed venture, map naturally to these layers:

1. Memory
2. Continuity
3. Governance
4. Trust
5. Institutional Intelligence operations
6. Resilience outcomes

### Pass Threshold

1. Every venture maps naturally to at least 4 layers
2. Most map explicitly to governance and continuity
3. Forced mapping language is rare

---

## Test 4 — Category Independence

### Prompt
If Nzila disappeared tomorrow, would "Institutional Intelligence" still be a useful way to describe an organizational capability?

### Pass Threshold
Majority clear yes

### Fail Meaning
The concept is still a vendor framework, not a category.

---

## Test 5 — Market Timing (Why Now)

### Prompt
Over the next five years, do you expect this capability to become more important, equally important, or less important?

### Pass Threshold

1. 70%+ say more important
2. 50%+ say significantly more important

### Fail Meaning
Category may be correct but premature.

---

## Test 6 — Causal Model Validation (A/B)

### Model A
Memory -> Continuity -> Trust -> Governance -> Institutional Intelligence -> Resilience

### Model B
Memory -> Continuity -> Governance -> Trust -> Institutional Intelligence -> Resilience

### Prompt
Which sequence better reflects how institutional trust is built in your organization, and why?

### Freeze Rule
If 65%+ choose Model B, freeze Model B as canonical.

## 5) Moderator Script (Copy/Paste)

## Opening (2 minutes)
Thank you for joining. We are evaluating whether a proposed capability category is useful and accurate for institutional leadership contexts. This is not a product demo and there are no right answers. We are testing clarity, relevance, and timing.

## Context Questions (5 minutes)

1. What institutional risks currently concern you most?
2. Where do leadership transitions create fragility?
3. Where do inconsistent decisions create downstream cost or trust issues?

## Test 0 (Problem Recognition) (5 minutes)
Ask the exact Test 0 prompt and score 1-5.

## Category Comprehension (Test 1) (6 minutes)
Read the 30-second category prompt and ask comprehension questions.

## Distinction (Test 2) (5 minutes)
Probe comparative credibility vs incumbents.

## Traceability (Test 3) (5 minutes)
Ask what product behavior would actually count as category-conformant.

## Independence + Timing (Tests 4 and 5) (4 minutes)
Run both prompts verbatim.

## Model A/B (Test 6) (4 minutes)
Present both sequences and capture choice plus rationale.

## Close (2 minutes)
What is one thing this category gets right, and one thing that still feels unclear?

## 7) Aggregation Rules

### Required Gate Condition
Test 0 must pass.

### Overall Go Rule
Proceed to category article only if:

1. Test 0 passes
2. At least 4 of Tests 1-5 pass
3. Test 6 yields model freeze

### No-Go Rule
Pause publication and revise category framing if any of the following occur:

1. Test 0 fails
2. AI reduction exceeds 40%
3. Category independence fails
4. Timing shows low urgency
