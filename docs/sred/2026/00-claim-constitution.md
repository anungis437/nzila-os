# 2026 SR&ED Claim Constitution

Purpose: protect the SR&ED claim from drift and enforce methodological consistency across all narratives, evidence, and costing.

Status: governing document for the 2026 claim cycle
Applies to: all SR&ED documentation under docs/sred/2026

## Claim Scope
The claim is for methodological advancement in:
1. Institutional Intelligence Measurement
2. Institutional Intelligence Knowledge Architecture
3. Continuity Intelligence Methodology
4. Healthcare Operational Continuity Intelligence

## Explicit Non-Claim Areas
Not claimed:
- marketing
- sales
- GTM activities
- demos
- UI design
- localization
- platform deployment
- authentication
- CRUD development
- standard integrations
- customer onboarding
- pilot implementation

## Claim Unit
Primary claim unit:
- Advancement

Not primary claim units:
- Project
- Feature
- Product
- Release

## Burden of Proof
Every advancement must be traceable to:
Uncertainty -> Experiment -> Failure or Result -> Learning -> Evidence

Minimum requirement for claimability:
- explicit uncertainty statement
- documented experiment(s)
- documented result or failure
- articulated learning
- linked evidence artifact(s)

## Evidence Hierarchy
Tier 1 (highest weight):
- code
- tests
- experiment outputs

Tier 2:
- ADRs
- methodology docs
- audit reports

Tier 3:
- meeting notes
- discussions

Tier 4 (lowest weight):
- retrospective reconstruction

## Governance Rules
- If an item cannot satisfy burden of proof, do not claim it.
- If uncertainty is absent, classify work as non-SR&ED.
- If evidence is only Tier 3/4, classify as weak support and seek Tier 1/2 corroboration.
- Non-eligible work must be captured in the exclusions register.

## Operating Sequence
1. Constitution
2. Advancement Registry
3. Failure Ledger
4. Research Timeline
5. Evidence Priority Matrix
6. Commit-level backfill

## Accountability
- Technical Lead owns methodological truth and uncertainty framing.
- Finance owns costing controls and allocation integrity.
- Consultant/CPA may align language and filing package but does not author technical facts.
