# CUPE Pilot Quick Start Guide

> For pilot administrators — get Union-Eyes running in 5 minutes.
>
> **See also:** [Admin Guide](../../union-eyes/admin-guide.md) · [Pilot Overview](../../union-eyes/pilot-overview.md)

## 5-Minute Setup

1. **Log in** at your Union-Eyes URL with your admin credentials
2. **Configure your worksite**: Admin → Employers/Worksites → Add your workplace name + employer
3. **Invite a steward**: Admin → Users → enter their email, select "Steward" role → Send Invite
4. **Verify**: Ask the steward to log in and confirm they can see the case dashboard

## 20-Minute Checklist

- [ ] Create a **test case**: Cases → New Case → fill in a sample grievance
- [ ] **Assign it** to your steward from the Workbench
- [ ] **Transition** it through the workflow: Submitted → Under Review → Assigned → Investigation → Resolved → Closed
- [ ] Check the **dashboard**: Dashboard → Leadership → confirm KPI cards update
- [ ] Review the **audit trail**: Open the test case → Timeline tab → verify all actions logged

## Going Live

1. Run the **Setup Checklist**: Admin → Setup → Checklist — all items should show ✅
2. Invite your **pilot members** (1–5 worksites, up to 200 members)
3. Share the **Member Quick Start** (see CUPE_PILOT_USER_GUIDE.md) with stewards + members
4. Monitor the **Workbench** daily for new and overdue cases

## Getting Help

- Email: Contact your platform support team
