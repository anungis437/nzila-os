## 9. Unresolved operational discipline risks

| Risk                                              | Mitigation plan                                  |
| ------------------------------------------------- | ------------------------------------------------ |
| Cadence creep into ritualism                      | Audit interpretively quarterly                   |
| Executive briefing inflation                      | Bound briefing word count + remove charts        |
| Onboarding acceleration pressure                  | Require sponsor + platform reviewer co-sign      |
| Rehearsal becoming theater                        | Continue rendering rehearsals on a separate ledger |
| Audit drift toward compliance bureaucracy        | Refuse scoring; render postures only             |
| First-pilot operator burnout                     | Daily light cadence is bounded to 15 minutes     |
| Cross-app vocabulary drift                        | Cross-app consistency doc is normative           |
