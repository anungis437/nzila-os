# FAIRCASE Pricing Model

## Commercial Packages

- Foundation: $24,000/year
- Growth: $48,000/year
- Enterprise: $84,000+/year

## Packaging Logic

- Foundation: core incident governance, baseline exports, up to 50 active users.
- Growth: adds advanced analytics, executive views, and expanded integrations.
- Enterprise: adds dedicated environments, premium support, and procurement controls.

## Optional Add-Ons

- Data migration and historical normalization
- White-glove onboarding and policy mapping
- Custom board and regulator reporting templates
- Advanced integration connectors

## Commercial Assumptions

- Average deal size: $52,000
- Average sales cycle: 90-95 days
- Target close rate: 18-20%
- Gross margin target: 80%+

## Contracting Notes

- Annual contracts by default
- Multi-year discounts by approval
- Public-sector procurement language available
- Security and privacy annex included in MSA
