# Union Eyes: Pricing Framework

*Version 1.0 — Internal Use / Pilot Discussions*

---

## Guiding Principles

1. **Pilot-first**: The entry point is always the 90-day pilot, not a multi-year commitment
2. **Membership-based**: Pricing scales with the organization, not the feature set
3. **No hidden costs**: No per-seat fees for stewards; no overage charges for grievance volume
4. **Simple credits**: Pilot fees convert 1:1 to subscription credit
