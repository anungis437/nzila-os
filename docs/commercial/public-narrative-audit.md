# Public Narrative Audit

Date: 2026-04-22  
Properties audited:
- https://nzilaventures.com
- https://unioneyes.app
- https://partners.nzilaventures.com

## Nzila Ventures (nzilaventures.com)

### What works

- Broad platform scope is visible.
- Credibility signals exist (status links, legal pages, infrastructure references).
- Contact paths are present.

### Clarity gaps

- Heavy macro language dilutes buyer clarity (`APEX`, `future`, large TAM emphasis).
- Too many parallel claims before clear buyer action.
- Trust claims are present but not front-loaded with proof links.

### Required message shape

- Who we are: Venture-backed operator building production software for regulated and mission-critical teams.
- What we build: Vertical products with shared compliance-grade platform.
- Why trust us: Live systems, documented controls, transparent metrics.
- How to work with us: Pilot, procurement, enterprise partnership.

## UnionEyes (unioneyes.app)

### What works

- Problem framing and workflow narrative are strong.
- Pilot CTAs exist (`Request a Demo`, `Start a Pilot`).
- Trust framing (`Built on trust, not surveillance`) is directionally strong.

### Clarity gaps

- Pilot CTA should include concrete procurement and security-review path in-page.
- Some impact numbers need explicit context labels (`pilot sample`, `timeframe`, `cohort size`).

### Required message shape

- Problem solved: Case delays and fragmented union operations.
- Who it serves: Reps, leadership, federations, members.
- Pilot CTA: Start 90-day pilot with success criteria.
- Trust CTA: Download trust package and security summary.

## Partners (partners.nzilaventures.com)

### What works

- Clear partner-function modules and onboarding CTA.
- Direct sign-up/sign-in links exist.

### Clarity gaps

- Enterprise procurement path is not explicit enough.
- Some stats (`120+ partners`, `92% renewal`) need proof context if public.

### Required message shape

- Partnership paths: reseller, implementation partner, strategic channel.
- Enterprise inquiries: dedicated contact and qualification flow.
- Procurement path: security pack, DPA, legal contacts, timeline.

## Immediate Copy Rules

1. Remove vague superlatives unless attached to evidence.
2. Keep every hero section answerable in 10 seconds:
   - what this is
   - for whom
   - what next step is
3. Pair every trust claim with a proof link.
4. Mark estimates/forecasts explicitly.
