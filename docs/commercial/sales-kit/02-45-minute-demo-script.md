# 45-Minute Demo Script

## Objective

Move from product tour to buyer confidence with a clear pilot decision path.

## Agenda (45 minutes)

1. 0:00-0:05 Context and buyer goals
2. 0:05-0:15 Intake-to-workflow live walkthrough
3. 0:15-0:25 Leadership and intelligence views
4. 0:25-0:32 Trust and security review
5. 0:32-0:40 Pilot scope proposal
6. 0:40-0:45 Q&A and next-step commitment

## Script Cues

### Intro

"Today we will show how UnionEyes reduces case friction from first intake to executive action, and exactly how we would measure pilot success for your organization."

### Workflow demo

- Show intake capture.
- Show assignment/triage.
- Show priority and progress view.
- Show export/reporting output.

### Trust segment

- Share Trust Center docs.
- Confirm data handling and access model.
- Explain incident and support path.

### Close

Ask for one of three commitments:
- technical validation session
- pilot design workshop
- procurement package review
