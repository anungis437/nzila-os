# Discovery Call Checklist

## Business Context

- What is the current case volume per month?
- What are the top 3 workflow bottlenecks?
- Which roles are most affected by current tooling?

## Technical Context

- Current systems in use (case mgmt, docs, communication).
- Data residency and compliance constraints.
- Security review requirements and timeline.

## Success Criteria

- Define 3 measurable pilot outcomes.
- Define baseline metrics and data source.
- Define executive review date and decision owner.

## Buying Process

- Budget owner identified.
- Procurement/legal path identified.
- Implementation sponsor identified.

## Exit Criteria

Call is successful when:

- a pilot hypothesis is agreed
- diligence package handoff is accepted
- next meeting is scheduled
