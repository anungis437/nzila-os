# Readiness certifications — dated records

> **Temporal status — HISTORICAL RECORD, NOT A CURRENT READINESS STATEMENT (added 2026-09-24):**
> every document in this directory certifies a state at its own date (this corpus was committed
> between 2026-07-03 and 2026-08-27). A `CERTIFIED`, `PASS`, or `production-ready` marking inside
> one of them describes the environment as inspected then, and does not establish that the same
> is true today. Disposition and dependencies are recorded in
> [`../DOCUMENT_DISPOSITION.md`](../DOCUMENT_DISPOSITION.md).

- `tooling/scripts/validate-br6-org-context.mjs` → `br6-org-context-closure.md`

Union Eyes readiness read [`../union-eyes/README.md`](../union-eyes/README.md) — the gate there is
authoritative over anything stated in this directory.
