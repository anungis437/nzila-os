# Nzila OS — Sovereignty Proving Layer

> **Doctrine authority.** Not aesthetics. Not feature plumbing. Operational stress-proving.

This layer exists to certify that Nzila OS behaves **institutionally correctly under operational stress** — not merely during healthy runtime conditions. It is the canonical operational stress-proofing authority and the upstream gate for the **Tier 2 Operational Sovereignty Certification**.

The proving layer presupposes that the substrate gates have already closed (see [`docs/nzila-tier2-hardening/`](../nzila-tier2-hardening/)). What it adds is **lived evidence** that the runtime degrades governance-safely, fails closed, preserves continuity under outage, and never overstates legitimacy.

The proving cadence is governance-safe, continuity-safe, anti-surveillance, evidence-anchored, and bounded by reviewer-of-record stewardship. Operational honesty is itself part of the product surface — institutional, embodied, calm, deterministic, inevitable, singular maturity under pressure.

## Operational honesty preface

This proving layer was authored from a **single live evidence pass** against the dev / staging / demo / pilot substrates on May 9, 2026. It does **not** yet include a full chaos-engineering campaign or a multi-week traversal corpus. Where evidence is partial, the verdict is **CONDITIONAL GO**; where the runtime is provably bounded under the probed degradation, the verdict is **GO**; where the runtime would silently overstate legitimacy or collapse ambiguously, the verdict is **NO-GO**.

This calibration is itself the doctrine: the proving layer must never overstate its own depth. Operational honesty is bound to the cadence of stewardship review — not to a one-time emission.
