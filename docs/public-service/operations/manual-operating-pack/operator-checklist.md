# Operator Checklist

> **Internal operating template. Not public copy. Not for external use unless separately reviewed and approved.**

One-page operator checklist for a manual CLEAR/SAGE proof run. Mark every check with a standard status
(see [kit-conventions.md](../kit-conventions.md), Section 3): **PASS** / **NEEDS REVIEW** / **N/A**. A run
is not clear while any required check is **NEEDS REVIEW**.

justified **N/A**. Any **NEEDS REVIEW** blocks completion until resolved.
