# CLEAR/SAGE Manual Operating Pack

> **Internal operating template. Not public copy. Not for external use unless separately reviewed and approved.**

## 1. Purpose

The Manual Operating Pack turns the [Manual Operating Readiness Summary](../manual-operating-readiness-summary.md)
into executable internal checklists and runbooks. It helps an internal operator complete future
fictional/internal CLEAR/SAGE proof runs without improvising scope boundaries, evidence-source
classification, authorized-only handling, boundary scans, decision records, retrospectives, or
packaging/export prohibitions.

This pack supports internal manual operation only. It does not create software, automation, product
availability, procurement readiness, external assurance, legal validation, regulatory assurance,
procedural-fairness validation, tribunal/ombuds assurance, clinical validation, compliance certification,
or public copy.

## 2. What this pack is

- A set of internal execution aids for running a manual CLEAR/SAGE proof run.
- A repeatable checklist-and-runbook layer over the Alpha Operating Kit and kit conventions.
- An internal control surface that keeps every proof run inside the canonical boundaries.

## 3. What this pack is not

- It is not software, a UI, or an automation.
- It is not a public route, product page, or availability claim.
- It is not a procurement, pricing, pilot, demo, or outreach asset.
- It is not legal, regulatory, procedural-fairness, tribunal/ombuds, clinical, or compliance validation.

## 4. When to use this pack

Use this pack whenever an internal operator is about to complete a new fictional/internal CLEAR/SAGE proof
run, or to review a completed run before its retrospective. It is also the reference for deciding whether a
calibration or a new proof run is warranted.

## 6. Required operating sequence

1. Confirm fictional/internal scope.
2. Select institution type before framing.
3. Choose the safe wedge.
4. Record red lines and exclusions.
5. Classify evidence sources.
6. Mark authorized-only placeholders.
7. Complete CLEAR brief.
8. Assemble manual SAGE workspace.
9. Complete assurance checklist.
10. Complete feedback integration decision record.
11. Run boundary scans.
12. Complete retrospective if the proof run is finalized.
13. Update proof-runs index.
14. Decide whether calibration is needed.
15. Do not package or export externally unless separately reviewed and approved.

## 7. Boundary posture

Every proof run must preserve: no prohibited conclusions, no scoring or ranking, no automated decisions, no
source-system replacement, no direct data-access assumption, no SAGE availability/product claim, no
public-copy drift, and all domain-specific exclusions (regulator, tribunal/ombuds, and deferred
health/PHI). See [kit-conventions.md](../kit-conventions.md).

## 8. Relationship to readiness summary

This pack operationalizes the decision recorded in the
[Manual Operating Readiness Summary](../manual-operating-readiness-summary.md): pause proof-run expansion and
package the manual operating model internally. The readiness verdict remains GREEN for internal fictional
dry runs, AMBER for real-institution use, and RED for external/public/software/product use.

## 9. Go / no-go posture

- **Go (internal):** completing fictional/internal proof runs, calibrating the kit, updating internal
  documentation.
- **No-go (without separate review):** public copy, product/SAGE availability, pricing, procurement,
  pilot/demo, real-institution targeting, health/PHI runs, external assurance, or any validation claim.

## 10. Maintenance rule

Treat kit conventions as mandatory. When a proof run, retrospective, or calibration changes an operating
rule, update the affected pack file in the same wave and keep the proof-runs index accurate. The pack must
never drift into public, product, or validation language.
