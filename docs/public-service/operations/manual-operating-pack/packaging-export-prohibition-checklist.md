# Packaging / Export Prohibition Checklist

> **Internal operating template. Not public copy. Not for external use unless separately reviewed and approved.**

## 1. Purpose

Prevent premature external packaging of CLEAR/SAGE proof-run materials. This checklist is a hard gate before
any material leaves internal use.

## 2. Absolute prohibitions

Do not export, package, publish, forward, sell, demo, price, pilot, or present CLEAR/SAGE proof-run
materials externally unless separately reviewed and approved.

No proof-run material may be used as public copy, sales collateral, procurement material, legal validation,
regulatory assurance, procedural-fairness validation, tribunal/ombuds assurance, clinical validation,
compliance certification, or external assurance package.

## 3. External-sharing gate

External sharing remains **NEEDS REVIEW**. Do not clear a proof run for external sharing from this pack;
external clearance requires separate review and approval.

## 4. Public-copy gate

- [ ] No proof-run text is reused as public copy.
- [ ] No summary is converted into a public page or outreach asset.

## 5. Product / procurement gate

- [ ] No SAGE availability, launch, or productization implied.
- [ ] No pricing, procurement, pilot, demo, or SOW language.

## 6. Real-institution gate

- [ ] No real institution named or targeted.
- [ ] No real institution named in negation.

## 7. Health / PHI gate

- [ ] No health-system, clinical, PHI, patient-data, or health-record readiness claim.
- [ ] Health/PHI work remains deferred unless a separately approved Proof Run 0.4 is opened.

## 8. SAGE availability gate

- [ ] SAGE is described only as a future-facing, manual, internal workspace pattern.
- [ ] No statement implies SAGE is available, launched, or procurement-ready.

## 9. Export checklist

| Gate | Required check | Status | Notes |
| --- | --- | --- | --- |
| External sharing | Marked NEEDS REVIEW | | |
| Public copy | None created | | |
| Product/procurement | None introduced | | |
| Real-institution | None named/targeted | | |
| Health/PHI | No readiness claim | | |
| SAGE availability | Future-facing only | | |

## 10. Completion rule

The export checklist is complete only when every gate is **PASS** (or a justified **N/A**) and external
sharing remains **NEEDS REVIEW**. Any external release requires a separate review-and-approval step outside
this pack.
