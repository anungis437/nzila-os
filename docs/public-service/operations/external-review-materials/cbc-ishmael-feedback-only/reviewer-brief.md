# Reviewer Brief

> **Controlled feedback-only reviewer material. Not public copy. Not a product, demo, pilot, procurement, pricing, or availability claim. Do not share unless owner-approved.**

## 1. Context

We are testing whether the CIVIC / CLEAR / SAGE framing is understandable and useful from a
public-institution change-management perspective. Your change-management vantage point is exactly the lens
we want to pressure-test the language against.

## 2. What we are asking you to react to

We would like your reaction to the framing itself — the words, the structure, and the boundaries — not to
any tool, roadmap, or engagement. Specifically:

- clarity of the CIVIC framing
- whether CLEAR reads like a credible evidence method
- whether SAGE is understandable as a future/manual workspace concept rather than available software
- whether the boundaries are clear enough
- what language would create confusion or concern inside a public institution

## 3. What this is not

This is not a product pitch, procurement conversation, pilot request, demo request, or request for
endorsement. It does not use CBC data, does not assess CBC, and does not ask CBC to participate in anything.

## 4. How to read the material

Read the four short summaries in any order — CIVIC, CLEAR, SAGE, and the boundary summary. They are meant to
be skimmable. Then use the feedback questions as prompts. If a summary takes more than a couple of minutes to
follow, that is itself useful feedback.

## 5. Feedback requested

React honestly to the framing and language. We are most interested in where wording is unclear, where a term
sounds like more than it should (for example, sounding like a product or a certification), and what a
change-management leader in a public institution would question first.
