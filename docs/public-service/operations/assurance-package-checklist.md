> must be confirmed before a package is shared.

## Checklist

**Scope confirmed**
- [ ] Institutional question stated
- [ ] Scope and exclusions explicit

**Institution type confirmed**
- [ ] Institution type selected from the adaptation framework
- [ ] Adaptation-matrix row applied

**Red lines confirmed**
- [ ] Institution-specific red lines recorded before evidence review
- [ ] Independence-bearing functions avoided

**Evidence provenance confirmed**
- [ ] Every source has provenance and confidence
- [ ] Evidence source register complete

**Source-system authority preserved**
- [ ] Reference/link first; copies justified and controlled

**Personal information minimized**
- [ ] No unnecessary personal or protected-domain material

**Confidence and uncertainty stated**
- [ ] Confidence level per finding
- [ ] Gaps and next evidence recorded

**Human-review path recorded**
- [ ] Reviewer(s) identified
- [ ] Human review completed

**No prohibited conclusions**
- [ ] See the prohibited-conclusions list below

**No product/procurement language**
- [ ] No product, procurement, pricing, pilot, demo, or SOW language
- [ ] SAGE not described as launched, available, or productized

**Export controls checked**
- [ ] Package cleared for its intended audience under controlled conditions

**Follow-up evidence identified**
- [ ] Next evidence needs logged

## Prohibited conclusions

A package must contain **none** of the following:

- legal conclusion
- HR conclusion
- equity or discrimination conclusion
- accessibility conformance conclusion
- Official Languages determination
- clinical conclusion
- enforcement conclusion
- adjudicative conclusion
- audit opinion
- compliance certification
- finding of wrongdoing, misconduct, racism, discrimination, or breach
- score / rating / ranking of people, groups, programs, or institutions

If any prohibited conclusion is present, the package is not cleared. Reframe as evidence-organizing
observations for human review, or stop.
