## Rules

- **Reference and link first.** Prefer a reference or link over a copy.
- **Copy only when necessary and controlled.** Note why a copy was required.
- **Do not request direct system access at first contact.**
- **Do not collect** enforcement, investigation, inspection, licensing, regulated-entity, complaint,
  adjudicative, privileged-legal, personal, case-specific, clinical, student, source-protected,
  journalistic, or Indigenous protocol-sensitive material unless explicitly authorized and necessary.
- **Preserve source-system authority.** The register never becomes the system of record.
- **State confidence and provenance** for every source, using the calibrated confidence levels
  (Insufficient / Low / Low–Moderate / Moderate / High); leave the open-question column honest.
- **Mark authorized-only sources.** Prefix the source name with `[AUTHORIZED-ONLY]`; such a source is
  never collected, copied, or accessed without explicit, recorded authorization and demonstrated
  necessity.

## Excluded material (not registered, not accessed)

Enforcement files, investigation files, inspection files, licensing case files, regulated-entity records,
complaint files tied to enforcement, adjudicative records, privileged legal advice, and personal
information are out of scope for this proof run and were not registered or accessed.
