# CLEAR/SAGE Proof Run 0.3 — Example Public Accountability Office

> **Fictional internal dry run. Does not refer to any real institution. Not for external use.**

## 1. Purpose

To test whether the calibrated CLEAR/SAGE Alpha Operating Kit can be run end to end on a tribunal/ombuds
question — from intake through evidence register, CLEAR brief, manual SAGE workspace, assurance checklist,
and feedback-integration decision — against an adjudication-adjacent, complaint-handling, and
protected-disclosure risk surface.

## 2. Fictional institution

Example Public Accountability Office (fictional; not a real institution).

## 3. Institution type

Tribunal / ombuds office.

## 4. Institutional question

How can the institution preserve complaint-pathway continuity, public-guidance traceability, accessibility
implementation evidence, and modernization reviewability without influencing complaint intake,
investigation decisions, protected disclosures, adjudicative or quasi-adjudicative processes, findings,
reasons, recommendations, remedies, or individual case outcomes?

## 5. Safe wedge

Complaint-pathway continuity + public-guidance traceability + accessibility implementation evidence +
modernization reviewability.

## 6. Risk surface tested

Adjudication-adjacent independence / complaint-handling / protected-disclosure / findings-and-recommendations
boundary risk. This proof run stresses the red-line pressure a tribunal/ombuds office creates around
complaint intake, investigations, protected disclosures, adjudication, findings, reasons, recommendations,
remedies, and individual case outcomes.

## 7. Files in this proof run

- `institution-intake.md` — completed intake worksheet
- `evidence-source-register.md` — completed evidence source register (public/administrative sources)
- `clear-brief.md` — completed CLEAR brief
- `sage-workspace.md` — completed manual SAGE workspace
- `assurance-package-checklist.md` — completed assurance checklist
- `feedback-integration-decision-record.md` — completed decision record (no public copy change)

## 8. What this proof run demonstrates

- The calibrated Alpha Operating Kit runs manually end to end on a tribunal/ombuds question.
- Institution type is selected before framing; tribunal/ombuds-specific red lines are recorded before
  evidence review.
- Source-system authority is preserved; personal information is minimized; complaint, investigation,
  protected-disclosure, adjudicative, and case-outcome material is excluded.
- CLEAR pillars are mapped with calibrated confidence levels and uncertainty stated.
- A SAGE-style workspace is assembled by hand with a manual-synchronization check.
- The assurance package remains human-reviewed, with prohibited conclusions avoided.

## 9. What this proof run does not demonstrate

This proof run demonstrates manual internal operation only. It does not demonstrate software, automation,
deployment, procurement readiness, tribunal or ombuds validation, legal validation, procedural-fairness
validation, assurance opinion, compliance certification, or product availability.

## 11. Relationship to the calibrated Alpha Operating Kit

This run exercises the conventions in
[kit-conventions.md](../../kit-conventions.md): the standard internal-use disclaimer, status definitions,
confidence levels, authorized-only marker, reusable risk-tier phrasing, and the manual-sync checklist. It

retrospective, not by changing public copy.
