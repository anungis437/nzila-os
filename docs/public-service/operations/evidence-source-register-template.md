## Rules

- **Reference and link first.** Prefer a reference or link over a copy.
- **Copy only when necessary and controlled.** Note why a copy was required.
- **Do not request direct system access at first contact.**
- **Do not collect** personal, case-specific, clinical, student, investigative, source-protected,
  journalistic, Indigenous protocol-sensitive, or privileged material unless explicitly authorized and
  necessary.
- **Preserve source-system authority.** The register never becomes the system of record.
- **State confidence and provenance** for every source, using the standard confidence levels
  (low / low–moderate / moderate / high); leave the open-question column honest.
- **Mark authorized-only sources.** Prefix the source name with `[AUTHORIZED-ONLY]` for any source that
  may only be used with explicit, recorded authorization. Such a source is never collected, copied, or
  accessed without that authorization and demonstrated necessity.
