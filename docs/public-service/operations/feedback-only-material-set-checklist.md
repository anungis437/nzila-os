## 1. Purpose

This checklist defines what may be included in a controlled, feedback-only external review material set for
CIVIC / CLEAR / SAGE. It does not create the material set, authorize outreach, or approve any public, demo,
pilot, procurement, pricing, or product artifact.

## 2. Source decision

Source: [external-review-readiness-decision.md](external-review-readiness-decision.md).

The source decision approves, in principle, one controlled, feedback-only external review only if all ten
GREEN → AMBER gate criteria are satisfied before any material is shared.

1. External reviewer is trusted / warm / bounded.
2. Review scope is feedback-only.
3. No real institution data is used.
4. No SAGE availability is implied.
5. No procurement/pilot/pricing language is included.
6. OCI/OCRA is not used as the public-service label.
7. CIVIC/CLEAR/SAGE hierarchy is explained cleanly.
8. Reviewer receives only approved materials.
9. Feedback is captured through the validation protocol.
10. Any follow-up artifact requires separate review.

## 4. Allowed material types

Allowed only if separately reviewed before sharing:

- one-page CIVIC framing summary
- short CLEAR method summary
- high-level SAGE concept summary, explicitly future/manual/non-product
- internal doctrine hierarchy excerpt, rewritten for reviewer context without exposing unnecessary internal
  history
- approved feedback questions
- boundary summary explaining what the review is not

Allowed does not mean approved. Every item must still pass the pre-share checklist and owner confirmation.

## 5. Prohibited material types

- proof-run folders
- proof-run retrospectives
- Manual Operating Pack
- internal doctrine map
- readiness summary
- source registers
- assurance checklists
- decision records
- scan outputs
- generated reports
- repo screenshots
- product screenshots
- SAGE UI mockups
- pricing pages
- procurement/SOW material
- pilot proposals
- demo scripts
- real-institution examples
- health-system / PHI / clinical material
- legal, regulatory, procedural-fairness, tribunal/ombuds, or compliance validation material

These materials may inform internal preparation, but they must not be sent externally under this gate.

## 6. Required packet constraints

Any reviewer material set must be:

- short
- feedback-only
- non-technical unless the reviewer specifically asks for method detail
- clear that SAGE is not available software
- clear that CLEAR does not certify, score, rank, adjudicate, or validate
- clear that CIVIC is not a procurement offer
- free of real-institution data
- free of pricing, demo, pilot, procurement, and SOW language
- free of OCI/OCRA as the public-service label

## 8. Reviewer instruction requirements

The reviewer must be told:

- this is not a product pitch
- this is not procurement outreach
- this is not a demo or pilot request
- this is not a request for endorsement
- this is a feedback-only framing review
- SAGE is not available software
- CLEAR is not a certification or validation claim
- CIVIC is the public-service framing
- any follow-up requires separate review

## 9. Feedback capture requirements

Capture feedback through the validation feedback operating layer. Require capture of:

- reviewer role/context, without over-identifying
- what framing was clear
- what framing was confusing
- boundary concerns
- terminology concerns
- institutional-fit reactions
- material that should not be used externally
- follow-up questions
- whether any follow-up artifact is requested
- decision on whether to integrate feedback

## 10. Follow-up control rule

No follow-up material may be created or shared externally unless it is separately reviewed and approved. A
reviewer request for more detail does not automatically authorize a deck, demo, proof run, product
description, pricing note, procurement note, SAGE workspace, or external assurance package.
