# Continuity matrix extension (optional)

> **Does NOT replace** the client's succession matrix, board pack, or HR plan.  
> This is an optional CLEAR/SAGE-aligned *extension* for continuity tracking.

## Suggested columns (add beside client matrix — do not overwrite)

| Extension column | Purpose |
| --- | --- |
| Continuity service ID | Stable id for a critical service line |
| Evidence source class | From `evidence-source-classes.yaml` |
| SAGE authorization level | public → excluded |
| Decision record id | Link when a human decision exists |
| Knowledge dependency ids | From `knowledge-dependency-map.md` |
| Unresolved flag | Boolean + owner |
| Last verified date | When continuity claim was last checked |

## Rules

- Client matrix remains system of record for succession *roles/people*.
- This extension tracks **continuity evidence and decisions**, not hiring outcomes.
- Never copy sensitive HR fields into a shared matrix without authorization level + grant plan.
