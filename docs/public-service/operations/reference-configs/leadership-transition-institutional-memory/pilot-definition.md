# Bounded pilot template — Leadership Transition / Institutional Memory

> Reusable template. Replace bracketed fields per engagement.  
> Example first case label (non-product): `[Example: municipal HR association leadership transition]`.

## 1. Purpose (one paragraph)

Help `[institution]` preserve **decision-relevant institutional memory** and
**continuity of critical services** across a defined leadership transition,
using CIVIC framing, CLEAR evidence discipline, and (when authorized) a SAGE
workspace — without automated decisions or certification claims.

## 2. In scope

- [ ] Named transition window: `[start date]` → `[end date]`
- [ ] Roles mapped from `institution-workspace.yaml`
- [ ] Evidence classes from `evidence-source-classes.yaml`
- [ ] Continuity discovery questions completed
- [ ] Human-authored decision records for material transition choices
- [ ] Explicit evidence grants for any sensitive/excluded material

## 3. Out of scope

- Pension / labour adjudication / entitlement advice
- Replacing the client's succession matrix
- Member365 / LRIS / payroll / recruitment ATS integrations (unless separately approved)
- Public launch, procurement language, or SAGE “availability” claims
- Real personal data in fixtures or demos (use fictional only)

## 4. Success conditions (qualitative — see success-metrics.md)

- Incoming role can reconstruct *authorized* rationale for key choices
- Restricted material remains inaccessible without grant (tested)
- Decision records cite evidence with source, date, and authority

## 5. Exit / pause criteria

- Boundary flag raised for real-institution risk without authorization
- Attempt to use inaccessible evidence in synthesis/export
- Scope creep into adjudicative or clinical domains
