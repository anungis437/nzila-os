# External-Send Package — for a first, non-confidential external review

> **Audience.** A single, senior, independent public-sector reviewer.
> **Purpose.** Solicit **judgment**, not endorsement. Legal verification of
> instruments, formal security attestation, and commercial term-sheet review
> are **out of scope** for this pass.
>
> **This folder is the *only* thing that should leave the building.** The wider
> government-readiness corpus (binder, blueprints, procurement readiness
> assessment, workbook, internal pre-mortem) is available on request but is
> **not** attached by default. The internal pre-mortem
> ([INTERNAL_PRE_MORTEM_HYPOTHETICAL_REVIEWER_CHALLENGES.md](../../INTERNAL_PRE_MORTEM_HYPOTHETICAL_REVIEWER_CHALLENGES.md))
> is a Nzila red-team exercise and **must not** be sent externally under any
> circumstance.

## Contents

1. [`01_COVER_EMAIL.md`](./01_COVER_EMAIL.md) — the framing note.
2. [`02_INDEPENDENT_REVIEW_BRIEF.md`](./02_INDEPENDENT_REVIEW_BRIEF.md) —
   5–7 page brief: the problem, the category hypothesis, the architecture,
   one worked finding, what is implemented, what is not yet verified.
3. [`03_REVIEWER_RESPONSE_FORM.md`](./03_REVIEWER_RESPONSE_FORM.md) — 5
   decisions the reviewer is uniquely placed to make (2 pages).
4. [`04_EVIDENCE_INDEX.md`](./04_EVIDENCE_INDEX.md) — pointers to the deeper
   materials (binder, tests, crosswalks, appendices), available on request.

## Send checklist

- [ ] Cover email personalised (single addressee, single ask, no distribution
      list).
- [ ] Brief and response form printed to PDF from the current commit; commit
      SHA recorded in [`../../EVIDENCE_MANIFEST.md`](../../EVIDENCE_MANIFEST.md).
- [ ] Internal pre-mortem excluded from attachments.
- [ ] Deeper materials (binder, blueprints, procurement readiness, workbook)
      **not** attached; linked only in `04_EVIDENCE_INDEX.md` as available on
      request.
- [ ] The reviewer is asked for **independent judgment**, not endorsement,
      and the out-of-scope items (legal, security attestation, commercial) are
      named explicitly.
