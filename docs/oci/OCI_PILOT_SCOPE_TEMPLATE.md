# OCI Pilot Scope Template

**ARTIFACT TYPE:** Institutional Doctrine — Scope Template
**DOCTRINE_VERSION:** 1.0.0
**STATUS:** Canonical
**INTENDED USE:** completed during activation, signed by sponsor and facilitator
**PARENT FRAMEWORK:** [OCI Institutional Activation](./OCI_INSTITUTIONAL_ACTIVATION.md)

> This is a template, not a finished document. It is completed
> during activation, signed by the sponsor and the facilitator, and
> filed with the institution's records. It is the written record
> that the engagement has been entered into deliberately.

---

## How to use this template

Copy this document into the institution's working space. Replace
each `[bracketed]` placeholder with the institution's own language.
Where a section is not applicable, write "not applicable" rather
than deleting the heading; absence is itself a record.

When the document is complete, the sponsor and the facilitator
sign the final page. The signed document is filed with the
institution's records and held by the facilitator.

## 5. Visibility posture

How visible is this engagement inside the institution?

- [ ] **Quiet.** Known to the sponsor, the governance liaison, the
      steward, and the facilitator. Other institutional staff are
      not informed.
- [ ] **Named within governance.** Known to the governance body
      (board, council, executive committee) by name; otherwise
      unannounced.
- [ ] **Open within institution.** Named to institutional staff
      via the sponsor's usual channel; not externally announced.
- [ ] **Externally referenced.** Named in the institution's
      external communications (annual report, governance
      communications). Note that this option is rarely chosen at
      activation; it is more commonly chosen after Phase 3.
