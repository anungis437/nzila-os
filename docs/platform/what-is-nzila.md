# What Is Nzila OS?

Nzila is a governed multi-product software group with one shared operating engine.

## What matters to an outsider

- What sells now: Union Eyes, Flow
- What is internal: Console, Control Plane, shared platform layers
- What is incubating: the remaining portfolio until proof improves
- What is cut-priority: Mobility Client Portal, Platform Admin, Orchestrator API

## Why the model is credible

- Canonical product truth in `governance/portfolio/product-catalog.json`
- Anti-drift validation in CI (`validate:product-catalog`, `validate:canonical-truth`)
- Explicit proof statuses (`no-proof`, `internal-proof`, `pilot-proof`, `paid-proof`, `scaled-proof`)
- Claim discipline: no paid/scaled claim without evidence
