# Nzila Institutional Engineering Implementation Profile

Nzila is a proprietary implementer and contributor to selected parts of the emerging discipline of Institutional Engineering. Nzila does not claim ownership of the field, universal adoption of its corpus, or complete implementation of its proposed constructs.

| Layer | Nzila position | Current authority |
| --- | --- | --- |
| Discipline | Contributor and commercial practitioner; not field owner | `IEBOK-0` is informative working governance |
| Governed corpus | Logical repository host pending source ingestion and naming decision | Corpus inventory and provenance register |
| Nzila doctrine | Proprietary implementation doctrine and controls | Existing doctrine governance |
| Methods | OCI, OCRA, CIVIC, SAGE, CLEAR, and adjacent methods remain distinct | Existing method documentation |
| Platform | Shared evidence, identity, authority, decision, policy, tenancy, observability, and audit primitives | Existing architecture and implementation evidence |
| Products | Bounded domain implementations | Product-specific doctrine and evidence |

The implementation profile is aligned only where an explicit adoption record later states its scope and evidence. Wave 1 contains no adopted IEBOK constructs; canonical corpus ingestion is distinct from Nzila adoption.
