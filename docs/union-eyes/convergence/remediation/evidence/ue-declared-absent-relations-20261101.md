# Convergence tranche 5: the 23 declared relations no migration created

Date: 2026-11-01. Branch `agents/ue-cursor-final-closure`. Base commit `e371980be`, source commit `5dfbd4467`. Platform migration `0061_declared_absent_relations`, cache migration
`0052_declared_absent_relations_rls_closure`.
Credit: none for the tranche itself (cross-cutting source evidence, `defectCredit` 0, `closureCredit` 0). Nothing is closed. `READY_FOR_STAGING` stays `NO`.

## What was wrong

Twelve relations the storage-authority manifest already classified (and eleven it declared as shared reference data) were named by Drizzle declarations that no migration, and not Django, created:
`anti_scab_violations`, `cnesst_filings`, `joint_hs_committees`, `pay_equity_exercises`, `preventive_withdrawals`, `right_of_refusal_events`, `wcb_claims`, `wcb_employer_assessments`,
`member_dues_issues`, `payroll_deductions`, `customer_nps_surveys`, `customer_onboarding_milestones` and the eleven `cba_intel_*` relations. Every route and service over one answered with an
undefined-relation fault (`42P01`), and a native test pinned the twelve as the known gap instead of fixing it. Running the unmodified routes and services against the real schema as the real roles then
found defects no mocked test could.

## What changed

- **Platform 0061** (+ rollback). Creates the 23 relations from their declarations (24 enum types, 69 indexes, 16 foreign keys), generated by `scripts/generate-relation-create.ts` through drizzle-kit,
  fail-closed (it refuses to run over an existing relation or a differently-shaped enum), tagged, reversible (the rollback refuses to drop a relation that holds rows or one it did not create), with every privilege
  revoked until the manifest grants it and a postflight on column counts and privileges.
- **Cache 0052** (+ rollback). Row security for the ten tenant tables through `ue_create_direct_org_rls_policy`; `customer_nps_surveys` and `customer_onboarding_milestones` are system-role-only; the eleven
  `cba_intel_*` relations are tenant-less shared reference data (manifest rounds 43 and 51) and take no policy.
- **The generic CRUD factory** (`lib/api/crud-factory.ts`): a JSON timestamp was handed to Drizzle as text (the driver throws), so a right-of-refusal event could never be created; missing required fields, a bad
  uuid, enum or date answered 500; a steward could not name the member a filing concerns. New `lib/api/crud-write-values.ts` (`normalizeWriteValues`, `parseIsoInstant`) and `lib/api/db-client-errors.ts`
  (`mapClientDatabaseError`: not-null 400 naming the property, unique 409, invalid input and check 400, foreign key 400 or 409 on delete, leaking no column, value or statement), and a `staffMayNameOwner` option
  (used by `app/api/cnesst/filings/route.ts`).
- **The dues portal.** `GET /api/dues/deductions` runs in the tenant transaction, returns only member-visible columns, newest first, bounded; `POST /api/dues/issues` validates and bounds its body, checks the amount
  fits `numeric(10,2)`, requires a uuid, accepts only the caller's own deduction and is audited; `components/dues/deduction-history.tsx` read the wrong envelope level and sent a user id the server ignores.
- **`ANY(array)`.** An array handed to `ANY(${values})` in a Drizzle `sql` template reaches PostgreSQL as `ANY(($1,$2))` (42809, 22P02 or 42846): the CBA benchmark had never run. Fixed with `inArray` or the new
  `lib/db/sql-in.ts` helper in the CBA benchmark, analytics queries and hybrid search, engagement scoring, consent manager, hierarchy validation, tenant mapper, the LMBP immigration service and the reward
  export and wallet services. `lib/db/__tests__/array-parameters.test.ts` scans the source for the spelling and refuses a new one (three finance statements and four column arrays were pinned; the finance ones are
  fixed in tranche 6).
- **Registers.** The census goes from 202 to 179 entries (exactly the `TABLE_ABSENT` ones), dispositions and the mutation-batch program are pruned and regenerated, the oracle, the canonical manifest (378 tables) and
  the disposition cards are republished, and the post-apply verifier's pin of the twelve absent relations became "every in-scope manifest entry has a physical table".
