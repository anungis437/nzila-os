# Union Eyes CLC Executive Visual Polish Checklist

Purpose: Deliver a restrained visual calmness pass that improves executive readability without redesigning flows or adding interaction complexity.

Do:
- Improve spacing rhythm and visual breathing room.
- Tighten typographic hierarchy and line length discipline.
- Reduce card density where readability suffers.
- Improve empty-state clarity and composure.
- Keep current IA and route structure intact.

Do Not:
- Add modules or screens.
- Introduce new interaction patterns.
- Re-architect components.
- Expand pilot-visible surface area.

## Polish Scope

In scope:
- Spacing tokens and section rhythm
- Heading/body hierarchy consistency
- Card padding and content chunking
- Empty-state composition and message order
- CTA prominence normalization

Out of scope:
- New workflows
- New data objects
- New role destinations
- New route exposure

## Heuristic Checks

1. Spacing rhythm
- Is vertical spacing consistent within each view?
- Are adjacent sections visually distinct without hard separators?
- Does any page feel cramped under demo zoom settings?

2. Typography hierarchy
- Is there a single obvious first read on every view?
- Are secondary labels visibly subordinate?
- Are line lengths comfortably scannable?

3. Card density
- Are cards carrying only essential decision information?
- Can any text be shortened without losing meaning?
- Are repeated metadata fields visually grouped?

4. Empty states
- Does each empty state explain status and next step?
- Is tone calm, institutional, and non-alarming?
- Is there exactly one primary action when action is needed?

5. Visual calmness
- Is there unnecessary visual noise competing with key narrative elements?
- Are warning accents reserved for true risk states?
- Do pages feel stable while speaking over them in a demo?

## Acceptance Criteria

- Executive and governance views pass readability at standard booth display settings.
- No new route, module, or component type introduced.
- No additional interaction complexity introduced.
- Stakeholder demos remain within target times after polish.

## Review Workflow

1. Capture before screenshots for each demo-critical view.
2. Apply minimal CSS/UI adjustments only.
3. Capture after screenshots.
4. Validate against this checklist.
5. Re-run a timed rehearsal for executive and governance demos.

Definition of done:
- Readability improved in before/after review.
- Presenter reports lower cognitive load while narrating.
- No script updates required to explain visual behavior.
