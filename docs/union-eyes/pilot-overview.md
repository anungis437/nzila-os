# Pilot Overview — Union Eyes (CUPE)

> What the pilot includes, how it works, and what happens next.

## What Is the Pilot?

The pilot is a time-limited trial of Union Eyes with a small group of CUPE
stewards and members. The goal is to validate that the system works for
real cases before rolling out to the full membership.

## What's Included

| Feature | Description |
|---|---|
| **Dashboard** | Simplified view with My Cases, Create Case, and Recent Activity |
| **Create Case** | Submit workplace issues with type, priority, and description |
| **My Cases** | View and filter your active and resolved cases |
| **Case Timeline** | Add updates, view history, and track status changes |
| **Onboarding Wizard** | 4-step first-login experience |
| **Feedback Widget** | Optional quick feedback after first case |

## What's Not Included (Yet)

The following features are intentionally deferred from the pilot to keep
things simple:

- Full grievance intake wizard (6-step CBA workflow)
- CBA Intelligence analytics
- Bargaining, strike fund, and pension modules
- Voting and elections
- AI assistant
- Health & safety and organizing campaigns

These will be evaluated for inclusion after the pilot concludes.

## How It Works

1. **Admin sets up** — Configures worksites, invites stewards (see [Admin Guide](./admin-guide.md))
2. **Stewards invite members** — Members receive email invitations to join
3. **Members create cases** — Workplace issues are tracked from submission to resolution
4. **Admin monitors** — Pilot dashboard shows adoption metrics and signals

## Pilot Boundaries

- **Users:** CUPE local members and stewards only
- **Duration:** Time-limited per agreement
- **Data:** Isolated within the organization's scope
- **Support:** Via [Admin Runbook](../pilot/cupe/CUPE_PILOT_ADMIN_RUNBOOK.md) and [Support SOP](../pilot/cupe/CUPE_PILOT_SUPPORT_SOP.md)

## Success Criteria

The pilot is considered successful when:

- ≥ 3 unique active users in the last 14 days
- ≥ 10 total cases created
- ≥ 5 total updates added
- Activity on ≥ 5 of the last 14 days

## What Happens After the Pilot?

If the pilot meets success criteria, the organization moves to full
deployment with access to additional features. If not, the admin and
platform team review feedback to address blockers.
