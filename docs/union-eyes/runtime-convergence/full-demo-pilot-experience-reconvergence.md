# Full Demo & Pilot Experience Reconvergence

> Doctrinal authorization to ensure demo and pilot environments embody **institutional operational infrastructure** — not feature tours, not workflow demos, not AI showcases.

## Objective

The demo must no longer feel feature-centric, workflow-centric, or AI-centric. It must increasingly feel **operationally real**.

## Required Targets

Converge across the demo and pilot environments (Azure Container Apps `nzila-os-union-eyes` demo + pilot):

- demo narrative (institutional stabilization story)
- pilot flows (continuity-safe, governance-safe institutional commitment)
- seeded data (operationally realistic, not toy)
- operational realism (real-looking institutional load)
- continuity realism (real succession scenarios)
- governance realism (real reviewer-of-record evidence chains)
- onboarding realism (institutional commitment cadence)
- procurement realism (calm, governance-readable, audit-readable)

## Required Implementation

Actually refactor:

- demo navigation (matches the canonical sidebar, not a custom demo nav)
- demo summaries (institutional, not promotional)
- demo scenarios (real institutional scenarios — pension, grievance, succession, modernization)
- seeded continuity flows (real handoff data)
- operational walkthroughs (executive + procurement + steward + member)
- executive demo posture (operational stabilization briefing)

## Demo Script Anchors

Existing demo scripts under [docs/union-eyes/clc/demo-scripts/](../../categories/products-and-market/union-eyes/clc/demo-scripts/) must be re-aligned with this layer:

- executive-demo
- governance-demo
- member-demo
- procurement-demo
- steward-demo

## Anti-Patterns to Eliminate

- **product-tour pacing** (clicking through every feature)
- **AI showcase scenes** (asking the AI to do something impressive)
- **toy data** (obvious lorem-ipsum, sample names like "John Doe")
- **demo-only nav** (a sidebar that only exists in the demo environment)
- **happy-path-only** scenarios (real operations include continuity disruptions)

## Scope Discipline

This document authorizes one PR (`refactor/ue-demo-pilot-experience-reconvergence`) covering demo seed data, demo nav, and demo scripts.
