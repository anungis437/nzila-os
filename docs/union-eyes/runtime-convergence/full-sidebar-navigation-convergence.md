# Full Sidebar & Navigation Convergence

> Doctrinal authorization to realign runtime navigation with **institutional operational infrastructure** doctrine across UE, Console, ExecutiveOS, Control Plane, and Ops surfaces.

## Objective

Navigation must increasingly feel **operationally inevitable** — not feature-organized, not SaaS-organized, not dashboard-organized, not workflow-organized. The sidebar is the public expression of institutional maturity, not a feature catalog.

## Required Targets

Converge across all surfaces:

- sidebars
- nav groups
- nav labels
- nav ordering
- nav semantics
- operational grouping
- executive grouping
- governance grouping
- cadence grouping
- onboarding grouping
- continuity grouping

Across:

- Union Eyes runtime (`apps/union-eyes`)
- Console (`apps/console`)
- ExecutiveOS surfaces
- Control Plane (`apps/control-plane`)
- Ops surfaces

## Required Implementation

Actually refactor:

- `nav-config` files
- sidebar components
- nav ordering arrays
- operational grouping containers
- cognition grouping containers
- governance grouping containers
- continuity grouping containers

## Canonical Surface Inventory

The runtime sidebar must express the seventeen institutional surfaces enumerated in [tier3-institutional-operating-infrastructure.md](../../categories/products-and-market/union-eyes/navigation-monetization-matrix/tier3-institutional-operating-infrastructure.md):

home, work, priority, outcomes, continuity, governance, cadence, onboarding, intelligence (renamed → cognition), executive, operations, assurance, memory, sovereignty, trust center, strategic operations, settings.

## Anti-Patterns to Eliminate

- **feature-organized** sidebars (e.g., grouping by "AI tools", "Reports", "Dashboards")
- **SaaS-organized** sidebars (e.g., free/pro/enterprise visibility differences without operational maturity context)
- **historically accumulated** ordering (where new items are appended without re-grouping)
- **workflow-centric** taxonomy (e.g., "wizards", "flows", "onboarding sequences" exposed as top-level)

## Required Posture

The sidebar must communicate **operational maturity progression**, not feature upselling. Every label must read as institutional, governance-safe, continuity-safe, and stewardship-aware. The runtime must feel calm under institutional load.

## Scope Discipline

This document authorizes a single PR (`refactor/ue-sidebar-navigation-convergence`) that realigns nav-config and sidebar components only. Route-rename PRs and IA-restructuring PRs are separate.
