# Full Live Runtime Experience Certification

> Doctrinal authorization to validate the runtime as a **lived institutional environment** across dev, staging, demo, and pilot.

## Objective

This validates **experiential legitimacy**. The certification confirms that the doctrine has been embodied in the lived runtime — not just documented.

## Required Validations

Validate across all four environments (dev / staging / demo / pilot):

- navigation coherence (sidebar reads as the canonical surface inventory)
- cognition coherence (bounded synthesis language is consistent)
- operational calmness (no notification spam, no urgency framings)
- continuity readability (continuity posture visible at every step)
- onboarding sustainability (institutional commitment cadence, not engagement gamification)
- procurement readability (calm, governance-readable, audit-readable)
- executive readability (operational stabilization briefing posture)
- governance readability (reviewer-of-record visible, audit-of-record reachable)
- operational pacing (cadence-aligned, not real-time-everything)
- institutional realism (no toy data, no product-tour pacing)
- operational inevitability (the runtime feels singular, calm, institutional)

## Environment Anchors

- **dev** — local docker-compose + native PG
- **staging** — `nzila-canada-staging-rg`, ACA `nzila-os-union-eyes`
- **demo** — Azure demo container app
- **pilot** — Azure pilot container app

## Required Implementation

Run real traversals (not synthetic checks):

- real runtime traversal (every sidebar item visited)
- real role traversal (executive, steward, member, procurement, governance)
- real executive walkthroughs (using the executive demo script)
- real procurement walkthroughs (using the procurement demo script)
- real onboarding walkthroughs (using the onboarding flow)

## Required Outputs

Certification produces:

- a verdict per environment (Mature / Fully Mature / Needs Refinement / Not Mature)
- a verdict per axis (navigation, cognition, calmness, continuity, onboarding, procurement, executive, governance, pacing, realism, inevitability)
- a list of unresolved fragmentation risks
- a final runtime maturity verdict

## Anti-Patterns to Eliminate

- **synthetic-only validation** (only running validators, never traversing the runtime)
- **happy-path-only certification** (skipping continuity disruption scenarios)
- **single-role certification** (only validating the executive view)
- **single-environment certification** (only validating staging)

## Scope Discipline

This document authorizes a single certification activity (not a code PR). The certification produces the [final-runtime-convergence-review.md](final-runtime-convergence-review.md) verdict.
