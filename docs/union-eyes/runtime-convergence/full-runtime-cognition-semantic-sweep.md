# Full Runtime Cognition Semantic Sweep

> Doctrinal authorization to converge all runtime cognition semantics — runtime copy, onboarding copy, operational summaries, cognition summaries, executive summaries, tooltip language, trust-center language, helper text, CTA wording — into one institutional language system.

## Objective

The runtime must increasingly speak **one institutional language system**: bounded synthesis, reviewer-of-record, evidence-anchored interpretation, governance-safe cognition, continuity-safe interpretation. Not assistant chatter, not agent autonomy, not AI insight magic.

## Required Targets

Refactor remaining language toward bounded-cognition framings:

| From | To |
|---|---|
| AI language | cognition |
| assistant language | bounded synthesis |
| agent language | reviewer-of-record |
| insight language | evidence-anchored interpretation |
| recommendation language | operational interpretation |
| automation language | governance-safe cognition |
| optimization language | continuity-safe interpretation |
| prediction language | bounded operational synthesis |

## Required Implementation

Actually refactor across `apps/union-eyes/` and `apps/console/`:

- runtime copy (page bodies, section guides, empty states)
- onboarding copy (welcome, walkthrough, completion)
- operational summaries (top-of-page narrative)
- cognition summaries (synthesis surfaces)
- executive summaries (briefing surfaces)
- tooltip language (hover, info, definition)
- trust-center language (governance, controls, posture)
- helper text (form helpers, CTA helpers, empty-state helpers)
- CTA wording (button text, link text)

## Canonical Vocabulary

Always prefer:

- **cognition** over "intelligence"
- **bounded synthesis** over "AI synthesis"
- **reviewer-of-record** over "approver" / "agent"
- **evidence-anchored interpretation** over "insight" / "recommendation"
- **operational interpretation** over "prediction" / "optimization"
- **governance-safe cognition** over "AI governance"
- **continuity-safe interpretation** over "smart automation"

## Anti-Patterns to Eliminate

- **"AI" as a noun** in runtime copy (use "cognition" or "synthesis")
- **assistant/copilot/agent** as user-facing labels (use "reviewer-of-record")
- **"smart" / "intelligent" / "powered by AI"** as marketing adjectives
- **"insights" as authoritative** without evidence-anchor framing
- **"recommendations" as autonomous** without reviewer-of-record framing
