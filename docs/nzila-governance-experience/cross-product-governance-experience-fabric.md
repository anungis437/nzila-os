# Cross-Product Governance Experience Fabric

> **Status:** Canonical governance experience · **Layer:** Cross-product fabric · **Inherits:** [cross-product-governance-operations-fabric.md](../nzila-governance-operations/cross-product-governance-operations-fabric.md)

## 1. Objective

Standardize governance operational UX across Union Eyes, FairCase, ExecutiveOS, Veridian, and any future Nzila product so the institution speaks one governance experience language.

## 2. Standardized surfaces

| Aspect | Standardization |
|---|---|
| Governance posture presentation | Posture card primitive from `@nzila/governance-operations` |
| Stabilization interpretation | Advisory phrasing from `@nzila/stabilization-signals` |
| Continuity review flows | Cards from `@nzila/continuity-review` |
| Deployment legitimacy review | Panels from `@nzila/attestation-visibility` |
| Evidence review UX | Sparse summary view; content-hash citation |
| Attestation visibility UX | Append-only, no silent downgrade |

## 3. Required uniform behaviors

- Every product renders bandings using the same banded shape.
- Every product cites the same doctrine references for the same governance categories.
- Every product refuses the same person-resolving content at every UI boundary.
- Every product honors the same role model.
- Every product refreshes on the same slow cadence.

## 4. Drift discipline

Per-product divergence is a doctrine-bearing regression. It is reverted or promoted into the shared contract by a doctrine-cited change.

## 5. Discipline

A cross-product fabric succeeds when a stakeholder can move between products and never need to re-learn what governance looks like.
