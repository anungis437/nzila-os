# ROI Calculator Assumptions (Pilot Stage)

## Baseline Inputs

- Monthly active cases
- Avg hours per case admin effort
- Avg grievance cycle time (days)
- Leadership report prep hours per period

## Benefit Inputs

- Admin reduction percentage
- Cycle-time reduction percentage
- Reporting-time reduction percentage

## Financial Inputs

- Loaded hourly rate per representative role
- Loaded hourly rate per leadership/reporting role
- Pilot fee
- Implementation support cost

## Formula Blocks

1. Admin savings = monthly cases x baseline admin hours x reduction % x hourly rate
2. Cycle-time value = monthly cases x cycle-time delta x value-per-day assumption
3. Reporting savings = report hours x reduction % x leadership hourly rate
4. Net pilot value = total quantified benefits - pilot and implementation costs

## Disclosure Rules

- All model outputs are estimates.
- Use customer-supplied baseline data whenever available.
- Do not present forecast as guaranteed outcome.
