> **Authority:** `docs/gtm/GTM_MASTER_OPERATING_SYSTEM.md`  
> **Owner:** Platform Owner  
> **Updated:** 2026-04-20  
> This is the commercial offer structure. These are the only offers. No custom scoping outside of this framework.

---

## Principle

Clean offers close faster than custom proposals. Every engagement must fit one of the defined offers below. If a prospect's needs don't fit, that is a scoping conversation — not a new offer.

---

## Union Eyes — Offer Stack

---

### UE-1: Discovery Sprint

**"Find out if Union Eyes fits your operation. No risk. 30 days."**

| Element | Detail |
|---------|--------|
| **Duration** | 30 days |
| **Format** | Demo environment — no production data |
| **Deliverables** | Workflow mapping report · Security + governance pack · Stakeholder walkthroughs (up to 3) · Go/no-go recommendation |
| **User count** | Internal evaluation team only (no end users) |
| **Pricing** | $7,000–$15,000 (org-size dependent) |
| **Buyer outcome** | "We understand exactly what it would take to implement Union Eyes and have written confirmation of fit or gaps." |
| **Upsell path** | → Controlled Pilot (natural next step if go-signal) |
| **Ideal for** | Executive directors who need internal sign-off before committing to a live pilot |

---

### UE-2: Controlled Pilot

**"Run Union Eyes with real cases, real users, real outcomes. 60 days."**

| Element | Detail |
|---------|--------|
| **Duration** | 60 days |
| **Format** | Live org environment, real cohort (5–50 users) |
| **Deliverables** | Provisioned org · Admin + end-user training · Weekly KPI reports · Evidence packs for all pilot cases · Outcome report at close · Conversion proposal |
| **Data** | New cases from go-live date OR scoped historical import |
| **Pricing** | $20,000–$40,000 (org-size + data complexity dependent) |
| **Buyer outcome** | "We have 60 days of real operational data, a complete KPI summary, and a clear decision on whether to continue." |
| **Upsell path** | → Annual Platform Plan (SaaS) · OR Production Pilot for full-department scale |
| **Ideal for** | Organizations with an active caseload and an executive sponsor ready to test in production |

---

### UE-3: Production Pilot

**"Full department deployment with a migration path and expansion roadmap. 90 days."**

| Element | Detail |
|---------|--------|
| **Duration** | 90 days |
| **Format** | Full department, no cohort restriction |
| **Deliverables** | Everything in Controlled Pilot + full data migration + train-the-trainer program + multi-year expansion roadmap + exec briefings |
| **Data** | Full historical migration from legacy system (scoped in Week 1) |
| **Pricing** | $50,000–$100,000+ (org-size + migration complexity) |
| **Buyer outcome** | "Our entire operation is live on Union Eyes with 90 days of evidence, a certified admin team, and a road map for Year 2." |
| **Upsell path** | → Multi-year Annual Platform Plan · Federation module |
| **Ideal for** | Organizations ready to fully migrate operations and commit to a governance-first platform |

---

### UE-4: Annual Platform Plan

**"Ongoing SaaS subscription — the operational platform for governed union operations."**

| Element | Detail |
|---------|--------|
| **Term** | Annual, upfront |
| **Format** | Dedicated org environment, full platform access |
| **Included** | All modules · Managed infrastructure (Azure Canada Central) · Security patches + upgrades · Automated backups (DR-documented) · Health monitoring · Enhanced support (P0: 2h; P1: 4h) · Monthly evidence packs · Quarterly governance snapshots |
| **Not included** | Custom integrations · New data migrations · On-site training · Custom reporting |
| **Pricing** | $24,000–$240,000/year (org-size dependent) |
| **Renewal uplift** | 8% standard; waivable for multi-year at signing |
| **Buyer outcome** | "We have a fully governed representation operation with ongoing compliance evidence, uptime commitment, and a vendor we can hold accountable." |
| **Upsell path** | Premium Support Add-on · Federation Module · Integration Pack · AI Intelligence Add-on |

## Packaging Rules

1. **Every engagement starts with a named offer.** No "we'll figure it out" scoping.
2. **Pilots are standalone offers, not free trials.** They have defined deliverables and a fixed fee.
3. **Add-ons are only offered post-pilot.** Do not bundle add-ons into pilot proposals.
4. **One offer per proposal.** If a prospect needs multiple things, scope them sequentially, not simultaneously.
5. **Federation Module is never sold without at least one local already on Annual Platform Plan.**
6. **If a prospect can't describe which offer they need, they're not ready to buy.** That's a discovery call, not a proposal.
