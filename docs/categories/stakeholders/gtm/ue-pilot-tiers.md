## Option A — Discovery Pilot

**30 days · $7,000–$15,000**

### What It Is

A structured exploration of Union Eyes against your current workflow. No live production use — a scoped demo environment is provisioned for your team to navigate, test, and evaluate.

### What Is Included

- Provisioned demo organization with pre-loaded sample data
- Workflow mapping session (2 hours): your current grievance process → Union Eyes model
- Up to 3 stakeholder walkthroughs with your team (Executive Director, lead steward, admin)
- Demonstration of: case intake, assignment, evidence capture, SLA tracking, officer dashboard, evidence pack export
- Security and governance packet delivery (org isolation, audit trail, RBAC, data residency)
- 30-day access to demo environment for independent exploration
- Written pilot readiness report at end of engagement

### What Is Not Included

- Live production cases
- Real member data
- Admin configuration by your team
- Integration with existing systems

### Exit Output

- Written summary of workflow fit, gaps, and configuration requirements
- Go/no-go recommendation for Option B
- Pricing for Option B if proceeding

### Who This Is For

Organizations that need executive-level confidence before putting real cases in a new system. Ideal for a pilot champion who needs internal approval before committing.

## Option B — Controlled Pilot

**60 days · $20,000–$40,000**

*Exact investment depends on org size, user count, and integration requirements.*

### What Is It

A live controlled deployment of Union Eyes with a real cohort of your team — real users, real cases, real outcomes, full KPI reporting.

### What Is Included

**Provisioning (Week 1)**

- Dedicated org environment provisioned (Canada Central, org-isolated)
- RBAC model configured for your role structure (member, steward, LRO, officer, admin)
- Admin accounts created; pilot cohort invited
- Monitoring and SLA alerting activated

**Onboarding (Week 1–2)**

- Admin training (half-day, remote): system configuration, user management, case routing
- End-user onboarding (2 hours per cohort group): intake, casework, evidence, reporting
- Support channel (dedicated Slack or equivalent) open for pilot duration

**Data**

- Option 1: Import a set of historical or active cases from your current system (scope agreed upfront)
- Option 2: Begin with new cases only from pilot go-live date
- Data mapping and import validation included; rollback documented

**Operations (Weeks 2–6)**

- Real case processing by your pilot cohort
- Daily health monitoring by Nzila ops team
- P0/P1 incidents: 4-hour response SLA
- Weekly KPI report shared with your leadership contact:
  - Case volume processed
  - Average time to first response
  - SLA compliance rate
  - Evidence packs generated
  - Active user count

**Evidence and Reporting (Weeks 6–8)**

- Evidence pack generated for every case closed during pilot
- Pilot outcome report: KPIs vs. baseline, incident log, stakeholder feedback summary
- Governance pack available for internal sign-off or procurement review

### What Is Not Included

- Custom workflow modifications beyond standard configuration
- Integrations with third-party systems (available as add-on)
- Unlimited data migration from legacy systems

### Exit Decision

At end of pilot, you receive:

- A complete KPI summary
- An evidence pack for all pilot cases
- A commercial conversion proposal for ongoing SaaS

Decision options: convert to SaaS, extend pilot, pause, or close.

### Who This Is For

Organizations with an active grievance workload and a team willing to run a live test. Requires an internal pilot champion and a cohort of 5–30 users.

## Option C — Production Pilot

**90 days · $50,000–$100,000+**

*Investment scales with org size, user count, data volume, and integration complexity.*

### What It Is

Full department deployment at production scale. Real migration path, full training, integration options, and an expansion roadmap built during the engagement.

### What Is Included

**Everything in Option B, plus:**

**Scale**

- Full department user base (no cohort restriction)
- Full data migration from legacy system (scope and complexity assessed in Week 1)
- Integration assessment and connection to at least one existing system (CRM, HR, document management)

**Training**

- Admin certification program (full admin team)
- Steward and LRO training program (all active reps)
- Executive reporting orientation (leadership team)
- Train-the-trainer package for ongoing internal onboarding

**Operations**

- Enhanced support: daily check-in during first 30 days
- Designated Nzila delivery contact for the duration
- Weekly executive briefing on pilot status

**Roadmap**

- Expansion roadmap workshop (Week 8): identify which additional modules unlock value
- Commercial structure for multi-year SaaS engagement

**Evidence and Governance**

- Monthly evidence packs for all cases processed
- Formal compliance snapshot at end of engagement
- Procurement pack (signed, verifiable) for internal audit or governance review

### Exit Decision

At end of pilot, you receive:

- Full KPI suite across all 90 days
- Evidence archive for the deployment period
- Expansion roadmap document
- Multi-year commercial proposal

### Who This Is For

Organizations ready to migrate their representation operations fully. Requires executive sponsorship, an internal delivery champion, and IT/admin capacity to participate in setup and training.

## Common Questions

**Can we start with Option A and upgrade?**
Yes. Every option is designed as a natural on-ramp to the next tier. Discovery → Controlled → Production is the recommended progression.

**What happens to our data after the pilot?**
All data remains in your org-isolated environment. If you do not convert to SaaS, data is exported to you in full and deleted from the environment within 30 days of pilot close.

**Do we need our own infrastructure?**
No. Union Eyes is fully managed by Nzila on Azure Canada Central. No IT infrastructure is required from your side.

**Can we run a pilot in parallel with our current system?**
Yes. Option A and Option B are explicitly designed to run alongside existing operations with zero disruption to your current workflow.

**What is the data residency model?**
All data is hosted in Azure Canada Central. Data does not leave Canada.

**What is the minimum org size?**
Option A is available for any org size. Option B requires at least 5 active users and a minimum active grievance workload to produce meaningful KPIs.
