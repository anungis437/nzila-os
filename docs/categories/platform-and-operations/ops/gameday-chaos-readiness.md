# Game Day and Chaos Readiness

## Quarterly Drill Scenarios

- Database outage.
- Auth outage.
- Region outage.
- Payment outage.
- Bad deploy rollback.
- Queue backlog and poison-message handling.

## Measurement

- Time to detect.
- Time to acknowledge.
- Time to mitigate.
- Time to recover.
- Communication SLA adherence.

## Success Gate

- Drill must complete with evidence log, recovery metrics, and action tracker.
