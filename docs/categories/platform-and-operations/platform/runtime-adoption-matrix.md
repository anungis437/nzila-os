# Nzila OS — Runtime Adoption Matrix

This matrix tracks concern-level adoption of the authoritative platform package map.

- Authority source: governance/platform-package-authority.json
- Exception source: governance/exceptions/platform-concern-adoption-exceptions.json
- Validation command: pnpm platform:adoption:check
- Machine report: governance/reports/platform-concern-adoption-report.json

Last updated: 2026-04-14

## Adoption Classifications

- fully adopted: all required concerns for app tier are adopted
- partially adopted: one or more required concerns are missing without active exception
- exception-approved: required concern gaps are covered by active exception entries
- legacy migration path: active exception indicates intentional staged migration
