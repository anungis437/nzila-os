## Rules for this directory

- Do not cite a document here as evidence that a capability is currently implemented,
  deployed, or proven.
- Do not delete material here because it is old. Historical failure and historical success are
  both part of the record.
- Do not edit archived documents to agree with today's conclusions. If something here is
  factually superseded, the correction belongs in the current authority, not in the archive.
- New archival material keeps its original wording; add context at the top rather than
  rewriting the body.
