# Live Operational Governance Panels

> **Status:** Canonical governance experience · **Layer:** Embedded panels · **Inherits:** [live-governance-review-panels.md](../nzila-governance-operations/live-governance-review-panels.md)

## 1. Objective

Embed live governance review panels into the runtime operational surfaces of every Nzila product so governance is continuously available, never a separate destination.

## 2. Required targets

| Host | Embedded panels |
|---|---|
| Control Plane | Posture overview, continuity band, legitimacy summary, decision ledger |
| ExecutiveOS (Console) | Posture summary, continuity briefing, modernization pacing |
| UE Ops (Union Eyes) | Pilot posture, pilot legitimacy, pilot decision queue |
| Pilot administration | Pilot scope evidence, pilot stabilization, pilot review queue |
| Deployment review systems | Release lineage, environment integrity, migration parity |

## 3. Required capabilities

Each embedded panel exposes:

- Live read of the relevant banded posture or verdict (slow refresh).
- One-click open of the underlying attestation or evidence record.
- Read-only by default; write access requires the role model's grant.

## 4. UX posture

Embedded panels render at the periphery of the screen, in the ledger register, never animate, and never compete with host-app content for attention.

## 5. Discipline

A live operational governance panel succeeds when operators stop seeking out separate dashboards because the panel itself is sufficient.
