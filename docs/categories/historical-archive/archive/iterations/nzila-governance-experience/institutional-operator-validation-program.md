# Institutional Operator Validation Program

> **Status:** Canonical governance experience · **Layer:** Validation · **Inherits:** [governance-experience-system.md](governance-experience-system.md)

## 1. Objective

Validate the governance experience with real institutional operators across roles, before declaring any maturity beyond `forming`.

## 2. Validation groups

- Executive operators.
- Governance reviewers.
- Deployment reviewers.
- Pilot operators.
- Continuity reviewers.
- Procurement-safe reviewers.

## 3. Validation areas

| Area | Method |
|---|---|
| Cognitive load | Time to confident read |
| Operational readability | Comprehension without orientation |
| Stabilization comprehension | Correct interpretation of bands |
| Legitimacy interpretation | Correct interpretation of verdicts |
| Governance trust | Self-reported trust after a session |
| Continuity understanding | Correct interpretation of trajectory |
| Operational calmness | Self-reported affect after a session |

## 4. Required outputs

- Governance readability reviews (text, banded).
- Operational calmness reviews (text, banded).
- Legitimacy interpretation reviews (per-surface).
- Continuity comprehension reviews (per-dimension).
- Stabilization usability findings.

## 5. Cadence

Validation runs on a quarterly cadence at minimum. Findings supersede prior maturity claims; never the reverse.

## 6. Discipline

Validation succeeds when operators describe the experience as "calm and clear" without prompting. Validation that requires interpretation by the validators themselves is rejected.
