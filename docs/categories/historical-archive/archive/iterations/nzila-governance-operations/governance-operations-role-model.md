# Governance Operations Role Model

> **Status:** Canonical governance operations · **Layer:** Role model · **Inherits:** [governance-operations-dashboard-system.md](governance-operations-dashboard-system.md)

## 1. Objective

Define operational visibility per stakeholder so each audience sees what it needs and nothing more — continuity-safe, least-surprising, anti-surveillance.

## 2. Stakeholder visibility map

| Stakeholder | Visible surfaces | Restricted surfaces |
|---|---|---|
| Executive leadership | Posture cards, continuity bands, attestation summaries, executive review workflows | Raw evidence, raw telemetry, individual-resolving content |
| Governance officers | All posture surfaces, full evidence explorer (banded), all attestations, governance review workflows | Person-resolving content (always) |
| Pilot operators | Pilot scope posture, pilot legitimacy attestations, pilot deployment verdicts | Production scope posture, cross-pilot data |
| Continuity reviewers | Continuity posture, stabilization signals, continuity evidence | Engineering-internal telemetry, deployment internals |
| Deployment reviewers | Deployment legitimacy panels, release lineage, environment integrity | Continuity person-data (always absent), executive review private notes |
| Auditors | Evidence explorer (full retention-class respecting), attestations, supersession history | Live operational dashboards (read-only access only), private review notes |
| Procurement observers | External-attestation-class artifacts, signed release statements (when available) | Live operational surfaces, internal review notes |

## 3. Posture

Visibility MUST be:

- **Least-surprising.** No stakeholder ever encounters a surface they were not expecting.
- **Continuity-safe.** Visibility never destabilizes the operating environment.
- **Anti-surveillance.** No stakeholder, at any tier, sees individual-resolving content.
- **Read-only by default.** Write access requires an additional doctrine-cited grant.

## 4. Discipline

A role model succeeds when each stakeholder feels well-served and the institution feels well-bounded. A role model that grants more visibility than warranted is a doctrine violation regardless of intent.
