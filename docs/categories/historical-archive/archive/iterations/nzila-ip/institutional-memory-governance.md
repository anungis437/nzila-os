# Institutional Memory Governance

> **Status:** Canonical · **Layer:** Governance doctrine · **Inherits:** Continuity Ontology, Governance-Safe Intelligence

Institutional memory is the substrate on which continuity is built. Its erosion is the most pervasive — and least visible — failure mode of long-lived organizations. This doctrine defines how Nzila products interact with institutional memory: what they retain, how, for whom, for how long, and under what governance.

Memory governance is **not** records management, log retention, or data warehousing. It is the doctrinal stewardship of the continuity-bearing substrate of the institution.

---

## 1. Memory Retention Philosophy

Doctrine holds that:

- Memory should be retained where its retention strengthens continuity
- Memory should be released where its retention is incidental, surveillance-prone, or continuity-neutral
- Retention is a governance choice, not a storage decision
- The default is **purposeful retention with stated horizon and audience**, not accumulation

Retention without purpose is a liability: it creates surveillance surfaces, increases breach exposure, and complicates governance.

---

## 2. Continuity-Sensitive Archival

Archival is **continuity-sensitive** when it preserves:

- Interpretive frames in their original context
- Decision rationale alongside decisions
- Vocabulary in use at the time
- Authority structures as they then existed
- Relational context of the moment

A purely event-based archive that strips interpretive context produces material that is technically present but interpretively useless to future role-bearers. Doctrine treats this as **pseudo-memory**: visible without being usable.

---

## 3. Governance-Safe Memory Access

Access to institutional memory is governed by:

- **Purpose** — access is justified by a stated, doctrinally legitimate purpose
- **Role exposure** — access aligns with the role's continuity exposure profile
- **Aggregation stance** — individual-level memory access respects the same constraints as individual-level signal aggregation
- **Reviewability** — access events are auditable; bulk access is governance-flagged
- **Reversibility** — access errors can be remediated without continuity damage

Memory access that bypasses governance is doctrinally prohibited even when technically possible.

---

## 4. Historical Interpretability

Future role-bearers must be able to **interpret** memory, not merely retrieve it. Interpretability requires:

- Vocabulary translation surfaces (when terms have shifted, prior terms remain accessible alongside their current equivalents)
- Authority context preservation (who held what authority at the time)
- Sequence preservation (what happened before/after)
- Decision-rationale preservation (why, not only what)
- Continuity-state preservation (the institution's posture at the time)

Interpretability is what distinguishes a useful institutional memory from a vast archive.

---

## 5. Institutional Forgetting Risks

Doctrine recognizes that memory loss compounds. Specific risks:

- **Embodied memory exit** — departures without transfer
- **Documented memory rot** — files unfindable, unreadable, unmaintained
- **Embedded memory fossilization** — processes preserved past their useful life, blocking renewal
- **Relational memory severance** — networks dying with departing relationships
- **Interpretive frame replacement** — new leadership replacing prior frames without preserving them
- **Vendor-trapped memory** — memory held in systems the institution does not control
- **Compliance-driven over-deletion** — memory destruction required by misapplied policy

Each risk is addressable; addressing them requires deliberate practice, not technology alone.

---

## 6. Organizational Memory Integrity

Memory integrity has multiple dimensions:

- **Completeness** — significant continuity-relevant material is preserved
- **Accuracy** — preserved material reflects what actually occurred
- **Findability** — preserved material is reachable by those who need it
- **Interpretability** — preserved material can be made sense of in its time
- **Provenance** — preserved material carries traceable origin
- **Authenticity** — preserved material is verifiable as un-tampered
- **Sovereignty** — the institution controls its own memory

Loss in any dimension reduces overall integrity.

---

## 7. Continuity-Preserving Retention Logic

Retention decisions follow this hierarchy:

1. Material whose absence would weaken continuity → retained with full interpretability
2. Material whose absence would impair governance reviewability → retained per governance horizon
3. Material whose presence enables interpretation of (1) and (2) → retained alongside
4. Material whose retention is required by external obligation → retained per obligation
5. Material whose retention serves no continuity, governance, or obligation purpose → not retained
6. Material whose retention would create surveillance surfaces → categorically not retained at the level enabling such surveillance

Doctrine biases toward **preserving interpretive richness for legitimate continuity purposes** and against **accumulating individual-level granularity**.

---

## 8. Memory Substrate Discipline

Memory exists across substrates. Each requires its own discipline:

| Substrate | Discipline |
|-----------|------------|
| **Documented** | Findability, currency, version stewardship |
| **Embedded (process)** | Periodic refresh; prevent fossilization |
| **Embodied (people)** | Transfer practices; succession-aware staffing |
| **Relational (networks)** | Bridge maintenance during transitions |
| **Interpretive (frames)** | Frame preservation across leadership changes |

Substrate-specific discipline prevents the common pattern in which one substrate is over-relied upon and the others atrophy.

---

## 9. Anti-Patterns

- **Vendor-locked memory** — memory portability not exercisable
- **Surveillance-grade retention** — individual-level granularity retained beyond legitimate purpose
- **Purposeless accumulation** — "save everything" defaults without purpose statements
- **Specialist-only access** — memory readable only by analytics specialists, not by role-bearers
- **Ahistorical interpretation** — present vocabulary applied to historical material without translation
- **Compliance theater** — retention/deletion driven by checkbox compliance rather than continuity reasoning
- **Lossless-archive fallacy** — assumption that complete retention equals complete memory

---

## 10. Memory and the Aggregation Stance

Memory governance inherits the aggregation stance discipline from [continuity-signals-taxonomy.md](continuity-signals-taxonomy.md):

- Individually meaningful memory is bounded to legitimate continuity uses
- Aggregate-only memory is not retained at the individual level
- Categorically off-limits-individually material is not retained at the individual level **even where technically straightforward**

This is one of the most important governance commitments in the doctrine.

---

## 11. Implications for Implementation

- Retention horizons are stated per data class, with doctrinal rationale
- Access logs are themselves part of memory governance
- Vocabulary changes are tracked alongside the vocabulary
- Decision records are first-class memory artifacts, not appendices
- Memory portability (export, transfer) is a structural property, not a feature request
- Memory interpretation surfaces are designed for non-specialists
