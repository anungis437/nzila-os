# Master IP Index

> **Status:** Canonical · **Layer:** Index · **Purpose:** Catalog every doctrine and framework with full strategic mapping

This index catalogs every document in the Nzila IP corpus, classifying each by objective, category, strategic role, commercialization relevance, licensing relevance, cross-product applicability, future legal/protective relevance, and continuity relationship.

It is the **single navigation surface** for the IP corpus and the canonical reference for all internal and external strategic conversations about Nzila's institutional IP.

---

## How to Read This Index

Each entry includes:

- **Document** — the file in the corpus
- **Objective** — what this doctrine or framework is for
- **Category** — meta-doctrine, foundational, architectural, operational, governance, field, strategic, or index
- **Strategic Role** — what role it plays in the overall IP stack
- **Commercialization Relevance** — its direct contribution to commercial pathways
- **Licensing Relevance** — its eligibility for independent licensing
- **Cross-Product Applicability** — its scope across the Nzila ecosystem
- **Future Legal / Protective Relevance** — implications for trademark, methodology protection, standards positioning, or independent IP filings
- **Continuity Relationship** — how it relates to the central continuity ontology
