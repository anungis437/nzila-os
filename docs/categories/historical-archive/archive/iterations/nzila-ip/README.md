# Nzila Institutional IP — Doctrine Stack

This directory contains the **formal doctrine corpus** of the Nzila ecosystem.

It is not product documentation. It is not marketing. It is not architectural reference.
It is the **codified institutional operating philosophy** that all Nzila products implement.

## What lives here

- **Doctrine** — conceptual systems describing how institutions behave, degrade, stabilize, and modernize
- **Frameworks** — operational methodologies derived from doctrine
- **Taxonomies** — formal classification systems used across products
- **Governance** — rules, hierarchy, drift control, and review processes

## What does NOT live here

- Product specs, API contracts, schemas, deployment topology
- Feature inventories, release notes, runbooks
- Marketing copy, positioning decks, sales narratives
- AI prompts, model configurations, infra code

Implementation lives in `apps/`, `packages/`, `services/`, `infrastructure/`.
**Implementation must conform to doctrine. Doctrine does not conform to implementation.**

Doctrine is governed under [doctrine-drift-governance.md](doctrine-drift-governance.md).
