# Full Role Experience Convergence

**Status:** Active
**Effective:** 2026-05-09
**Authority:** [master-finalization-index.md](./master-finalization-index.md)

This document finalizes stakeholder operational coherence across the
Nzila ecosystem.

---

## 1. Roles in scope

| Role                  | Where they operate                                      |
| --------------------- | ------------------------------------------------------- |
| Executive             | Console                                                 |
| Governance operator   | Control Plane                                           |
| Rollout operator      | Control Plane (CLI + Rollout dashboard)                 |
| Onboarding operator   | UE + Control Plane                                      |
| Continuity reviewer   | Control Plane                                           |
| Pilot operator        | UE                                                      |
| Steward               | Control Plane                                           |
| Reviewer              | Control Plane + Console                                 |
| Administrator         | Control Plane + Console                                 |

---

## 2. Convergence validations

| Validation                  | Result | Note                                                |
| --------------------------- | ------ | --------------------------------------------------- |
| Operational readability     | STRONG | Sparse panels; calm vocabulary                      |
| Navigation continuity       | STRONG | Same groupings per role across apps                 |
| Governance continuity       | STRONG | Same authority docs cited                           |
| Cadence continuity          | STRONG | Same cadence rhythm vocabulary                      |
| Stabilization interpretation| STRONG | Identical minutes-remaining semantics               |
| Operational calmness        | STRONG | No alarms; no scoring; quiet weeks legitimate       |

---

## 3. Refusals enforced at the role layer

| Refusal                                 | Enforcement                              |
| --------------------------------------- | ---------------------------------------- |
| No per-role scorecards                  | doctrine + validator anti-pattern guards |
| No role hierarchy implied in posture    | UI grammar — same posture for all roles  |
| No role-specific continuity overrides   | continuity-safe-rollout-system.md        |

---

## 4. Posture

Roles feel institutionally coherent across apps. A pilot operator
opening Console reads the same vocabulary; an executive opening
Control Plane reads the same posture. Role transitions never
require relearning.
