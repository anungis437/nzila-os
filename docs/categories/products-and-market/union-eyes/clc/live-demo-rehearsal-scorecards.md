# Union Eyes CLC Live Demo Rehearsal Scorecards

Purpose: Run disciplined human rehearsals for executive, governance, steward, and procurement flows exactly as scripted, and produce actionable polish decisions without adding scope.

Rules:
1. Use the frozen scripts in docs/union-eyes/clc/demo-scripts/ without adding content.
2. Time each run end-to-end.
3. Capture only clarity, pacing, and confidence issues.
4. Convert findings into polish tasks, not system changes.

Success Criteria:
- Executive demo: 12-15 min, no trust gap moments, no dead transitions.
- Governance demo: 10-12 min, explainability posture remains clear and calm.
- Steward demo: 10-12 min, operational continuity remains understandable.
- Procurement demo: 8-10 min, no feature overreach or technical drift.

## Run Plan

Session cadence:
- Round 1: Baseline rehearsal (one presenter per role)
- Round 2: Improvement rehearsal (same presenter)
- Round 3: Swap rehearsal (backup presenter)

Observers:
- 1 narrative observer (clarity/confusion)
- 1 pacing observer (time/tempo/dead space)
- 1 trust observer (confidence/governance comfort)

Scoring scale:
- 5 = Exceptional
- 4 = Strong
- 3 = Acceptable with edits
- 2 = Risky
- 1 = Blocker

## Universal Observation Grid (all demos)

Track each segment:
- Segment name
- Planned time
- Actual time
- Drift (+/-)
- Clarity score (1-5)
- Confidence score (1-5)
- Confusion moments
- Presenter notes
- Required adjustment

## Executive Demo Scorecard

Target duration: 12-15 min

Score categories:
- Institutional framing is immediate (1-5)
- Proof narrative is believable (1-5)
- Route transitions are smooth (1-5)
- Executive value is explicit (1-5)
- Objection handling feels composed (1-5)

Common failure patterns to flag:
- Overexplaining platform internals
- Jumping ahead of audience context
- Losing continuity between marketing and app
- Unclear next action at end

## Governance Demo Scorecard

Target duration: 10-12 min

Score categories:
- Explainability confidence (1-5)
- Audit and evidence clarity (1-5)
- Exposure boundaries are clear (1-5)
- Governance language discipline (1-5)
- Risk controls are believable (1-5)

Common failure patterns to flag:
- Ambiguous who-can-see-what explanations
- Mixing pilot and post-pilot language
- Any accidental promise beyond frozen scope

## Steward Demo Scorecard

Target duration: 10-12 min

Score categories:
- Workflow calmness (1-5)
- Case continuity readability (1-5)
- Document/task progression clarity (1-5)
- Escalation logic plausibility (1-5)
- Day-to-day usefulness credibility (1-5)

Common failure patterns to flag:
- Interface hopping with no narrative bridge
- Case status transitions not contextualized
- Too much technical vocabulary for frontline use

## Procurement Demo Scorecard

Target duration: 8-10 min

Score categories:
- Procurement-safe framing (1-5)
- Proof and controls clarity (1-5)
- Scope restraint discipline (1-5)
- Buyer confidence trajectory (1-5)
- Close and follow-up clarity (1-5)

Common failure patterns to flag:
- Feature pitch tone replacing institutional tone
- Security/governance claims without context
- No clear pilot boundary reminder

## Debrief Template (after each run)

1. What created confidence immediately?
2. Where did attention drop?
3. What triggered confusion?
4. Which transitions felt abrupt?
5. What should be removed (not added)?
6. What exact script line change is needed?

Decision rules:
- If a fix requires new module/feature: reject before CLC.
- If a fix improves pacing/clarity without scope change: accept.
- If a fix risks pilot truth drift: reject.

## Daily Rehearsal Log

For each run, record:
- Date/time
- Demo type
- Presenter
- Total duration
- Mean score
- Top 3 risks
- Top 3 edits
- Confidence to present live (Low/Medium/High)

Exit gate before CLC:
- All 4 demo types have at least two High-confidence runs.
- No category scored below 4 in final rehearsal cycle.
- No unresolved trust/confusion blocker remains.
