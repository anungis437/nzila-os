# Final UX Structure (Across All Tiers)

> The institutional UX posture that must be present in every tier, on every surface.

## 1. Required UX Posture

Across all tiers, the UX must increasingly feel:

- calm
- institutional
- operational
- continuity-safe
- governance-native
- non-chaotic
- cadence-aware
- stabilization-oriented

## 2. Forbidden UX Posture

Across all tiers, the UX must **not** feel:

- SaaS-like
- dashboard-heavy
- AI-centric
- notification-addictive
- workflow-maximalist
- engagement-optimized
- productivity-bait
- gamified

## 3. Surface-Level UX Discipline

| Discipline | Requirement |
|------------|-------------|
| Density | Calm; no metric overload. |
| Color | Institutional, low-saturation; no growth-hack accents. |
| Motion | Bounded, governance-safe; no notification animations designed to addict. |
| Empty states | Operational guidance; no engagement bait. |
| Notifications | Cadence-aware; never engagement-optimized. |
| Labels | Operational responsibility, never feature-name marketing. |
| Microcopy | Continuity-safe, governance-readable. |

## 4. Cross-Tier Consistency

The same UX posture is required at every tier. Tier 4 customers must not perceive Tier 1 customers as receiving a "lesser, gamified" product, and Tier 1 customers must not perceive Tier 4 surfaces as gated upsell bait. The institutional posture is invariant across the maturity ladder.

## 5. Anti-Pattern Reference

The following are explicitly prohibited at every tier:

- "Upgrade to unlock" CTAs styled as conversion bait
- AI-first hero framings on any tier surface
- chatbot launchers persistently floating across the interface
- engagement notifications, streaks, badges, gamified counters
- productivity-maximalist dashboards
- workflow-automation-first language
- copilot or assistant-style framings

These anti-patterns directly contradict the institutional category posture and must not appear regardless of tier.
