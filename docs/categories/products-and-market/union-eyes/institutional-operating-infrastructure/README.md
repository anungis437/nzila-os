# Union Eyes — Institutional Operating Infrastructure

**Canonical UE institutional transformation authority layer.**

## Purpose

Codify Union Eyes' transformation from labor-AI SaaS into **Institutional Labor Operating Infrastructure**. This layer governs UE's category, packaging, gating, monetization, navigation, procurement posture, and market narrative.

## Phase Discipline

This phase is **category transformation**, not cosmetic refresh. It is **not**:

- AI-first repositioning
- pricing tweaks
- marketing cleanup
- terminology refresh
- automation maximalism

It is:

- packaging realignment around operational maturity
- gating realignment around continuity / governance / executive maturity
- monetization realignment around institutional resilience
- positioning realignment around continuity-safe modernization
