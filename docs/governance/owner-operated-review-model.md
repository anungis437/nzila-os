# Owner-Operated Review Model

This repository is owner-operated.

Aubert Nungisa is the authorized owner and governance/security approver for repository-level review decisions. Governance and security approval labels may be applied by the authorized owner when acting in that capacity.

This does not bypass technical gates. CI validation, production-readiness gates, documentation validation, branch-policy checks, and release evidence requirements remain mandatory where configured.

For audit clarity:

- owner approval authority must be explicit when governance/security labels are applied;
- production-readiness gates must not be weakened to force a merge;
- release tags must not be moved casually after publication;
- SR&ED claim files must remain separate from deployment, governance, and production-hardening evidence unless deliberately updated for claim documentation;
- branch-protection or review-policy changes should be documented when they materially affect merge flow.

This model reflects the current repository operating reality: a sole authorized owner may approve governance/security posture, while automated gates continue to provide technical control evidence.
