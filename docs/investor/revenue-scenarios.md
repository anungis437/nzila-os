# Revenue Scenarios (Assumption-Based)

## Important Constraint

These are scenario frameworks, not booked revenue statements.

## Variables

- Active pilots per quarter
- Pilot-to-paid conversion rate
- Average contract value by product tier
- Gross retention in first 12 months
- Implementation capacity

## Scenario Bands

- Conservative: low conversion, constrained implementation throughput
- Base: moderate conversion with steady implementation execution
- Upside: strong conversion plus expansion within existing accounts

## Governance Rule

Scenario updates must cite source assumptions and date.
No scenario may be represented externally as realized revenue.
