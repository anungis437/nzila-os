# @nzila/oci-confidence

Runtime confidence infrastructure for the OCI Method™.

- **Universal Confidence Model™** — every OCI output carries a stable, sample-size-aware, decay-aware confidence envelope.
- **Stability Engine™** — longitudinal stability classification from explicit volatility signals.
- **Confidence Decay** — temporal degradation of assessment confidence under the doctrine schedule.
- **Data Completeness** — completeness scoring with caution emission.
- **Interpretive Cautions** — the canonical caution vocabulary.
- **Visual Model** — calm, procurement-safe surfacing structures (ribbons, badges, summaries).

All modules are pure, deterministic, side-effect-free, and contain no AI. Confidence states never imply probability and never imply ranking.

See [docs/oci/methodology/OCI_METHOD_WHITEPAPER_v1.md](../../docs/oci/superseded/methodology/OCI_METHOD_WHITEPAPER_v1.md) §7 (Confidence model) and the methodology extensions added under the operationalization sprint.
