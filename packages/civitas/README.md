# @nzila/civitas

Phase 0–1 foundation for CIVITAS, the specialist for lawful autonomy, jurisdiction, and continuity.

CIVITAS advises and analyzes. It does not deploy, merge, transact, file, or sign, and it is not counsel of record. Personal data is not stored. Later phases in `docs/doctrine/civitas/` are targets.

Evidence references come from `@nzila/platform-decision-engine`. The legal domain label comes from `@nzila/decision-core`. Entity names used as future targets come from `@nzila/platform-ontology`. This package does not replace those primitives.
