# @nzila/platform-jurisdiction-compliance

Multi-jurisdiction compliance policy framework for regulated operations across Nzila OS.

## Owns

- Jurisdiction-specific policy definitions and regulatory rule sets
- Validation utilities for compliance checks by region
- Test datasets used to verify policy behavior and coverage

## Does Not Own

- Application workflow orchestration for approvals
- Storage and transport of evidence artifacts

## Use This When

- Applying region-aware compliance validation in platform services
- Evaluating policy outcomes for Kenya, Uganda, Nigeria, and future regions
- Building automated compliance gates in release workflows

## Adjacent Packages

- @nzila/platform-governance: governance policy orchestration
- @nzila/platform-evidence-pack: evidence packaging for compliance outcomes
