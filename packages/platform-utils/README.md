# @nzila/platform-utils

Platform utility functions for time formatting and ISO timestamp generation.

## Capabilities

| Area | Functions |
|------|-----------|
| **Time** | `nowISO` — current time as ISO 8601 string |
| **Time** | `toISO` — convert Date to ISO 8601 string |

```
└── __tests__/
```
