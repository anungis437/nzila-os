No JSX, no message bundle, no schema, no route, no API contract, no edge runtime, no auth surface is touched. The fence makes future drift toward *greenfield / empty / sparse / demo / placeholder / instant-deploy / vanilla / pristine / toy* framing **structurally unutterable**, independent of which author writes the next surface or in which locale.
