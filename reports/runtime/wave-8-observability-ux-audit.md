## Section 1 — The Ten Audit Questions

### 1. Which observability surfaces feel category-defining?
- `institutional-observability` — chronology-linked, provenance-stamped, governance-safe read-only visibility
- `governance-center` — governance-of-record posture; explainability overlays mature
- `chronology` — governance epochs + procedural timelines; continuity-linked overlays
- `topology` — affiliation structures, governance lineage, delegation pathways, coexistence boundaries
- `institutional-memory` — provenance-aware, continuity-linked references
- `continuity-intelligence` / `continuity-planning` / `continuity-simulation` — stewardship-oriented, non-predictive, calm framing
- `cognition` / `longitudinal-cognition` — explainable-state framing; no scoring posture
- coexistence + federation visibility — federation-safe, redaction-respecting, coordination-of-record

### 2. Which surfaces remain visually generic?
Secondary surfaces (`inbox`, `workbench`, `priorities`) retain functional but visually thin treatment — Wave 9+ deepening candidates. Wave 8 vocabulary block prevents future deepening from drifting toward `activity stream` / `live monitoring` / `performance graph` aesthetics.

### 3. Which chronology surfaces lack temporal clarity?
Primary chronology surfaces have calm temporal rails, procedural chronology cards, governance epochs, continuity-linked breadcrumbs. Wave 8 fences `chronology dashboard`, `chronology monitoring` to prevent regression toward live-monitoring aesthetics.

### 4. Which topology surfaces lack institutional readability?
Primary topology surfaces communicate institutional structure, procedural relationships, governance lineage. Wave 8 fences `graph analytics`, `network analytics`, `influence graph`, `node graph`, `network monitoring`, `topology dashboard` to permanently block drift toward node-graph chaos / influence-mapping / social-network aesthetics.

### 5. Which continuity cognition surfaces remain conceptually dense?
Primary cognition surfaces are stewardship-oriented and continuity-aware. Continuity cognition retains calm/procedural framing rather than alarming/risk-scoring framing — Wave 3 fence preserved, Wave 8 reinforces via `continuity monitoring`, `predictive observability`.

### 6. Which provenance overlays remain hard to interpret?
Provenance ribbons + explainability layers are mature on primary surfaces. Wave 8 fences `observability analytics`, `observability scoring`, `observability monitoring` to preserve read-only institutional-evidence framing.

### 7. Which explainability overlays remain overly technical?
Explainability overlays answer the "why does this institutional state exist?" question on primary surfaces. Wave 8 vocabulary fence prevents future deepening from drifting toward "what institutional intervention should occur?" (alert/optimization posture).

### 8. Which surfaces drift toward dashboard aesthetics?
No primary surface currently drifts. Wave 8 hard-fail block targets `observability dashboard`, `institutional dashboard`, `chronology dashboard`, `topology dashboard`, `operational command center`, `governance command center`, `continuity command center`, `observability command center` to prevent future drift.

### 9. Which surfaces lack continuity-aware navigation?
Primary navigation is procedural / calm / continuity-aware / institutionally grounded. Wave 8 fences command-center posture to ensure navigation never drifts to productivity-oriented / command-oriented / enterprise-control-oriented framing.

### 10. Which surfaces fail to communicate institutional sophistication visually?
Primary surfaces communicate sophistication through visual calmness (archival-modern hierarchy, muted palettes, continuity-linked overlays). The few Wave 8 weak-tier surfaces (secondary inbox/workbench/priorities) are doctrinally fenced rather than re-skinned in this wave — preserving runtime stability.
