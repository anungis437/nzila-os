# Institutional Governance Graph (IGG) — Phase 1 Audit

**Status:** Audit only. No code, schema, RBAC, or runtime changes. Markdown deliverables.
**Scope:** Union Eyes (`apps/union-eyes/`) plus shared platform packages it depends on.
**Date frame:** Phase 1 — repo-grounded constitutional & governance mapping.

This folder contains seven sibling deliverables. Read in order:

1. [governance-graph-audit.md](governance-graph-audit.md) — what is already in the repo and what shape it takes.
2. [governance-graph-ontology-map.md](governance-graph-ontology-map.md) — the implicit entity / relationship / event vocabulary.
3. [governance-graph-collision-risks.md](governance-graph-collision-risks.md) — where current modeling will resist Phase 2.
4. [governance-graph-integration-opportunities.md](governance-graph-integration-opportunities.md) — where existing primitives can be composed instead of rebuilt.
5. [governance-graph-recommended-boundaries.md](governance-graph-recommended-boundaries.md) — proposed package / module ownership lines.
6. [governance-graph-domain-language.md](governance-graph-domain-language.md) — canonical terminology (the lexicon Phase 2 must respect).
7. [governance-graph-phase2-readiness.md](governance-graph-phase2-readiness.md) — what is ready, what is missing, what must precede Phase 2.

**Non-negotiables honored throughout:**

- Additive, not disruptive. Existing tables, packages, and routes stay.
- No academic graph-theory framing. The repo already calls these things by their institutional names — we keep those names.
- This is a *foundation* document for democratic institutional infrastructure. It is not a feature roadmap.
- Phase 2 is **not** implemented in this audit.
