# Union Eyes ROI Case For A CUPE Pilot

## ROI Thesis

Union Eyes can create real value for a CUPE local by reducing lost intake information, speeding assignment, improving status visibility, and producing defensible evidence packs. That value is real only if the pilot is run through the approved workflow and not through the currently miswired legacy member path.

## Value Drivers

1. Faster assignment through a structured queue and assignment API.
2. Better staff continuity through timeline, notes, and audit visibility.
3. Lower arbitration preparation cost through sealed evidence export.
4. Better leadership visibility through pilot metrics and case-state data.

## Early ROI Metrics

1. Median time from intake to assignment.
2. Median time from intake to first acknowledgment.
3. Percentage of cases with complete evidence at first staff review.
4. Staff hours saved preparing one grievance file for escalation or hearing.

## Cost Risks

1. Rework cost if staff must compensate for broken member intake paths.
2. Trust cost if members believe they submitted evidence that did not land in the right case workflow.
3. Support cost if pilot operators need to remember which routes are safe.

## CFO-Level Interpretation

This is not yet a mass-efficiency product. It is a high-touch pilot that can prove operational savings and defensibility benefits in a controlled environment.
