# Unit 92 Discovery Campaign

## Campaign purpose

Run a short anonymous survey on one unit to identify the safest first scheduling workflow wedge for a governed pilot.

## Target local/unit

- Local: UNA Local 115
- Unit: Unit 92, Short Stay Cardiology
- Site context: Foothills Medical Centre / FMC (configurable)

## Champion label

- Heather Haberli (internal-only label)

## Survey template used

- Unit Scheduling Experience Survey
- 15 core scheduling/discovery questions
- optional free-text discovery question
- optional short-stay cardiology context free-text question

## Privacy assumptions

- anonymous-by-default responses
- no respondent name/email fields
- no patient/employee/manager identifying data collection
- no grievance-intake framing
- no employer-audit framing
- free-text warning and redaction review status

## Expected outputs

- top scheduling friction signal
- strongest first workflow signal
- top adoption concern
- deterministic first wedge recommendation
- recommendation confidence

## Next decision point

After minimum response threshold is reached and free-text review status is applied, choose one tiny pilot wedge and governance boundaries for implementation.
