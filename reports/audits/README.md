# Audits

Comprehensive audit reports and assessments across platform domains.

## Categories

- **Console audits** — console-*-audit.md files, business OS audit, gap analyses
- **Technical audits** — architecture, repo excellence, package dependencies, RBAC, workflow
- **Readiness assessments** — ops readiness, validation reports, hardening summary
- **Data & documentation** — doc consistency, readme audit

## Key Reports

| Report | Purpose |
|--------|---------|
| `repo-excellence-audit.md` | Overall repository quality and standards |
| `architecture-audit.json` | Platform architecture compliance audit |
| `console-phase2-audit.md` | Console app phase 2 readiness assessment |
| `ue-security-rbac-audit.md` | Union Eyes RBAC and access control audit |
| `zonga-auth-rbac-audit.md` | Zonga authentication and role-based access audit |
| `sre-reliability-audit.json` | Site reliability engineering assessment |
