# Proof Artifacts

Tamper-evident proof packs and control evidence generated by certification and runtime pipelines.

## Areas

- [ai-controlled-request/](./ai-controlled-request/) - Evidence for AI-controlled request governance
- [compliance-sensitive-action/](./compliance-sensitive-action/) - Compliance-sensitive action proofs
- [event-contract-flow/](./event-contract-flow/) - Event contract integrity and replay evidence
- [ue-governed-mutation/](./ue-governed-mutation/) - Union Eyes governed mutation proofs
- [operational-proving/](./operational-proving/) - Operational validation packs
- [rollout-attestations/](./rollout-attestations/) - Rollout and release attestation artifacts
- [finalization/](./finalization/) - Finalization outputs and signed proof bundles
- [evidence-packs/](./evidence-packs/) - Monthly proof bundles (`2026-04`, `2026-05`, etc.)

## Root Summaries

- `latest-proof-summary.json` - Latest consolidated proof status
- `zonga-aws-e2e-smoke.json` - Zonga AWS E2E smoke validation snapshot

## Storage and Retention

Generated pack payloads may be gitignored by design.
Authoritative long-term storage is in Azure Blob Storage, with this directory acting as the local working/index surface.
