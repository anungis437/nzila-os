# Resume executif

Les organisations investissent souvent massivement dans :
- la technologie
- la conformite
- les communications
- les operations

Pourtant, les systemes de continuite restent sous-developpes.

La continuite institutionnelle n est pas une surcharge administrative.
C est une infrastructure de gouvernance.

# Contexte et probleme

Des systemes de continuite faibles creent :
- de l instabilite d integration
- de l incoherence de gouvernance
- de la perte de memoire institutionnelle
- de la fragmentation operationnelle

Ces risques se composent dans le temps.
