# veridian-site

Veridian Health public-facing marketing and onboarding site.

## Status

**Stage:** INCUBATION — active development. Not yet GA.

## Development

```bash
pnpm dev      # starts on port 3010
pnpm build
pnpm typecheck
pnpm lint
```

## Environment

Copy `.env.example` to `.env.local` and populate the required values.

## Related apps

- `apps/veridian-admin` — admin portal
- `apps/veridian-care` — care portal
