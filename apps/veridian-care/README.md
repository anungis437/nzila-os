# veridian-care

Veridian Health patient care portal — primary app for patients and care providers.

## Status

**Stage:** INCUBATION — active development. Not yet GA.

## Development

```bash
pnpm dev      # starts on port 3011
pnpm build
pnpm typecheck
pnpm lint
```

## Environment

Copy `.env.example` to `.env.local` and populate the required values.

## Related apps

- `apps/veridian-admin` — admin portal
- `apps/veridian-site` — public-facing site
