# Runtime Artifacts

Runtime captures and debug outputs generated during QA, CI, and local validation.

## Folders

- `ci-debug/` - CI diagnostics and troubleshooting outputs
- `logs/` - Execution logs and failure traces
- `ue-pw/` - Playwright output set 1
- `ue-pw2/` - Playwright output set 2
- `ue-srv/` - Service runtime capture set 1
- `ue-srv2/` - Service runtime capture set 2
- `ue3/` - Additional Union Eyes runtime artifacts

## Note

These artifacts are operational/debug data. They are organized for quick triage rather than long-term canonical documentation.
